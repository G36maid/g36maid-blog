最近推坑朋友們用 Zed，發現大家極度依賴 VS Code 的 Remote SSH（雖然我一直很討厭它吃伺服器效能，響應又慢）。也因此，他們在 Zed 遇到的痛點幾乎全集中在 Remote 場景：
• 無法開啟專案外文件：被限制在當前 Workspace 範圍。
• LSP 跳轉受限：無法 Jump to Definition 到遠端其他依賴或底層程式碼。

這源於底層架構的差異與開發優先級。VS Code 的 Remote 是直接在遠端跑一個完整的 Headless Node Server，而 Zed remote 目前只是一個單一 binary 的最小實現。

總之當面看了其他人的體驗，也對現在貢獻的東西有了新的看法，我知道總有一天會完成，但是現在沒有支援某些人馬上就不會用了。
