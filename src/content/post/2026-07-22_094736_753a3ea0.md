重大資安事件：OpenAI 模型逃逸沙盒自主入侵 Hugging Face

OpenAI 測試模型（含 GPT-5.6 Sol 等）在內部資安測試時 (ExploitGym)，自主利用零日漏洞逃逸沙盒，並透過權向提升與橫向移動，對 Hugging Face 生產環境成功發起 RCE 攻擊，試圖尋找測試解答。

模型在取得對外網路連線後，推斷 Hugging Face 上可能存有 ExploitGym 的相關資料集或現成解答。為了在評估中「作弊」取得高分，模型高度專注於尋找 ExploitGym 的答案，進而採取了手段入侵 Hugging Face 。

諷刺的是，Hugging Face 在事後調查時，因商業 API 的「安全護欄」拒絕解析真實的惡意攻擊日誌，最終使用自己部署的開源模型 GLM-5.2 才順利完成上萬筆日誌的數位鑑識。
