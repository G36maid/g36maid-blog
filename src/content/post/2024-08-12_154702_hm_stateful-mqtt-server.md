This is a stateful MQTT server implemented using the Paho MQTT client library. The server can handle various requests from clients and maintains a "magic list".

## Features

- Connect to an MQTT broker.
- Handle client requests:
  - `menu`: Display available options.
  - `0`: Get the server's local time.
  - `1`: Display the current content of the magic list.
  - `2`: Add a random integer to the magic list.

## Installation

1. Ensure Python 3.x is installed.
2. Install the required Python package:

    ```sh
    pip install paho-mqtt
    ```

## Usage

1. Edit the `stateful-server.py` file to set the correct MQTT broker address, username, and password.
2. Run the server:

    ```sh
    python stateful-server.py
    ```

## Notes

- Ensure the MQTT broker address, username, and password are correct.
- Modify the `to_client` and `to_server` topic names as needed.

# sub-net.py

This Python script uses the `paho-mqtt` client to connect to an MQTT broker, subscribe to all topics, and store received messages in a JSON file.

## Requirements

- Python 3.x
- `paho-mqtt` library

## Installation

1. Install Python 3.x.
2. Install the `paho-mqtt` library using pip:

    ```sh
    pip install paho-mqtt
    ```

## Usage

1. Download the `sub-net.py` script to your local machine.
2. Run the script:

    ```sh
    python sub-net.py
    ```

## Script Explanation

- `on_connect(client, userdata, flags, rc)`: Called when the client connects to the broker. If successful, subscribes to all topics.
- `on_message(client, userdata, msg)`: Called when a message is received. Stores the message in a nested dictionary and writes it to a JSON file.
- `client.connect("test.mosquitto.org", 1883, 60)`: Connects to the MQTT broker.
- `client.loop_forever()`: Keeps the client running and waiting for messages.

## File Structure

Received messages will be stored in the `received` directory, with filenames corresponding to the timestamp of when the message was received (format: `YYYY-MM-DD_HH-MM-SS.json`).

## Notes

- Ensure the `received` directory exists, otherwise the script will not be able to write files.
- If you need to connect to a different MQTT broker, modify the parameters in `client.connect`.

## Example

Below is an example of a JSON file generated by the script:

```json
{
    "home": {
        "livingroom": {
            "temperature": 22.5,
            "humidity": 45
        }
    }
}
```

# electricity_monitor

The `electricity_monitor` script uses an MQTT broker to monitor the power usage of multiple machines and simulate building power usage. The data is then displayed on a Grafana chart.

## Requirements

- Python 3.x
- `paho-mqtt` library
- Grafana

## Installation

1. Install Python 3.x.
2. Install the `paho-mqtt` library using pip:

    ```sh
    pip install paho-mqtt
    ```

3. Install Grafana following the official documentation.

## Usage

1. Download the `electricity_monitor.py` script to your local machine.
2. Edit the script and set the correct MQTT broker address, username, and password.
3. Run the script:

    ```sh
    python electricity_monitor.py
    ```

4. Open Grafana and configure a new data source to connect to the MQTT broker.
5. Create a new dashboard and add a chart to display the power usage data.

## Script Explanation

- `on_connect(client, userdata, flags, rc)`: Called when the client connects to the broker. It subscribes to the necessary MQTT topics.
- `on_message(client, userdata, msg)`: Called when a message is received. It processes the received data and updates the power usage information.
- `client.connect("mqtt_broker_address", 1883, 60)`: Connects to the MQTT broker.
- `client.loop_forever()`: Keeps the client running and waiting for messages.

## File Structure

The power usage data will be stored in a JSON file named `power_usage.json`.

## Notes

- Make sure the MQTT broker address, username, and password are correct.
- Modify the MQTT topics and data processing logic according to your specific requirements.
