## 在 Arch Linux 上安裝 Contest Management System (CMS)


### 1\. 安裝系統依賴 (Dependencies)

首先，我們需要安裝所有必要的系統套件

推薦使用 `paru` 或其他你習慣的 AUR helper，這樣就可以一次性安裝來自官方軟體庫和 AUR 的所有套件。

```bash
# 使用 paru 一次安裝所有官方與 AUR 的套件
paru -S --needed base-devel jdk8-openjdk fpc \
  postgresql postgresql-client python libcap \
  postgresql-libs libcups libyaml python-pip \
  libcgroup cppreference-doc-en-html
```

> **Note:**
> 如果你不想一次裝完，可以分開處理：
>
> 1.  先用 `pacman` 安裝官方套件。
> 2.  再手動從 AUR 安裝 `libcgroup` 和 `cppreference`。

#### 可選套件 (Optional)

若你需要 Web Server、PHP 管理後台、或是更多程式語言的支援，可以安裝以下套件：

```bash
paru -S --needed nginx php php-fpm phppgadmin texlive-core \
  a2ps ghc rust mono pypy3
```

### 2\. 下載 CMS 原始碼

從官方 GitHub repository clone 指定 `v1.5` branch 的原始碼。`--recursive` 參數會一併下載所需的 submodules。

```bash
git clone --recursive --branch v1.5 --single-branch https://github.com/cms-dev/cms.git
cd cms
```

### 3\. 設定 Python 虛擬環境並安裝 CMS

接下來，建立一個獨立的 Python 虛擬環境來安裝 CMS 的 Python 依賴。這裡我們用 `uv` 這個 moderno 的工具來處理，速度快，就是爽。

```bash
# 建立 venv
uv venv ~/cms_venv

# 啟用 venv
source ~/cms_venv/bin/activate

# 安裝 requirements.txt 中的依賴，然後安裝 cms 本體
uv pip install -r requirements.txt
uv pip install .
```

### 4\. 設定系統環境 (prerequisites)

CMS 需要一個名為 `isolate` 的沙箱工具來安全地執行使用者提交的程式碼。執行官方提供的 script 來完成設定。

```bash
sudo python3 prerequisites.py
```

執行過程中，script 會詢問是否要將你目前的使用者加入 `cmsuser` group。

  * **回答 `Y` (Yes)**： script 會自動幫你處理好。
  * **回答 `N` (No)**： 你需要手動將自己加入群組：
    ```bash
    sudo usermod -a -G cmsuser $USER
    ```

無論哪種方式，都需要重新載入群組設定，讓變更生效：

```bash
newgrp cmsuser
```

你可以用 `groups` 指令來確認自己是否已在 `cmsuser` 群組中。

### 5\. 建立 PostgreSQL 資料庫與使用者

CMS 使用 PostgreSQL 作為後端資料庫。我們需要建立一個專用的 user (`cmsuser`) 和 database (`cmsdb`)。

```bash
# 切換到 postgres 系統使用者
sudo -u postgres -i

# 建立名為 cmsuser 的資料庫使用者，並設定密碼
createuser --pwprompt cmsuser

# 建立名為 cmsdb 的資料庫，擁有者設為 cmsuser
createdb --owner=cmsuser cmsdb

# 調整 schema 權限
psql -d cmsdb -c "ALTER SCHEMA public OWNER TO cmsuser"
psql -d cmsdb -c "GRANT SELECT ON pg_largeobject TO cmsuser"

# 完成後，退回你自己的使用者
exit
```

### 6\. 設定 PostgreSQL 連線權限

為了讓 CMS 可以透過帳號密碼連線到資料庫，需要修改 PostgreSQL 的 HBA (Host-Based Authentication) 設定。

```bash
# 找到 pg_hba.conf 的路徑
HBA_CONF=$(sudo -u postgres psql -Atc "SHOW hba_file")
echo "PostgreSQL HBA config file is at: $HBA_CONF"

# 編輯該檔案 (請用你習慣的編輯器)
sudo nano "$HBA_CONF"
```

在檔案的**最上方**加入以下兩行，允許 `cmsuser` 從本機連線到 `cmsdb`：

```ini
# TYPE  DATABASE        USER            ADDRESS                 METHOD
host    cmsdb           cmsuser         127.0.0.1/32            md5
host    cmsdb           cmsuser         ::1/128                 md5
```

修改後，重新啟動 PostgreSQL 服務讓設定生效：

```bash
sudo systemctl restart postgresql
```

### 7\. 複製並設定 CMS config

將官方提供的設定檔範本複製到指定路徑。

```bash
sudo cp config/cms.conf.sample /usr/local/etc/cms.conf
sudo cp config/cms.ranking.conf.sample /usr/local/etc/cms.ranking.conf
```

接著，編輯主設定檔 `/usr/local/etc/cms.conf`，找到 `database` 欄位，填入你在步驟 5 設定的密碼。

```bash
sudo nano /usr/local/etc/cms.conf
```

```json
// ...
"database": "postgresql+psycopg2://cmsuser:YOUR_PASSWORD_HERE@127.0.0.1:5432/cmsdb",
// ...
```

### 8\. 初始化資料庫與建立管理員

萬事俱備，只欠東風。啟用 Python venv 後，執行以下指令來初始化 CMS 資料庫綱要 (schema) 並建立第一位管理員。

```bash
# 記得啟用 venv
source ~/cms_venv/bin/activate

# 初始化 DB
cmsInitDB

# 新增一位名為 'admin' 的管理員
cmsAddAdmin admin
```

### 9\. 啟動 CMS 服務

現在可以啟動 CMS 的各項服務了。

```bash
# 啟動所有在 cms.conf 中定義的 resource services (例如評測機)
cmsLogService 
cmsResourceService -a
```
```bash
# 啟動管理員用的 Web Server
cmsAdminWebServer
```
```bash
# 啟動公開用的 Ranking Server
cmsRankingWebServer 
```

> **Note:**
> 為了方便管理，你可能會想把這些服務註冊成 systemd units，但對於臨時架設或測試來說，手動啟動就足夠了。

### 10\. (可選) 匯入比賽範例

為了確認安裝是否成功，可以下載官方的範例比賽並匯入系統。

```bash
# 下載範例
git clone https://github.com/cms-dev/con_test.git
cd con_test

# 記得啟用 venv
source ~/cms_venv/bin/activate

# 匯入使用者和比賽
cmsImportUser --all -L italy_yaml .
cmsImportContest -i -L italy_yaml .
```

匯入成功後，你就可以打開瀏覽器，用 `admin` 帳號登入後台看看比賽是否已經出現了。

## Ubuntu 版 CMS 安裝流程

### 1. 安裝系統套件

```bash
sudo apt update
sudo apt install -y build-essential openjdk-8-jdk fpc postgresql postgresql-client \
    python3 python3-venv python3-pip libcap-dev libcups2-dev libyaml-dev \
    nginx php php-fpm texlive-latex-base a2ps ghc rustc mono-runtime pypy3
```

> 💡 若 `openjdk-8-jdk` 無法安裝，請改用：
>
> ```bash
> sudo apt install -y openjdk-11-jdk
> ```

---

### 2. 下載 CMS 專案

```bash
git clone --recursive --branch v1.5 --single-branch https://github.com/cms-dev/cms.git
cd cms
```

---

### 3. 建立 Python 虛擬環境並安裝 CMS

```bash
python3 -m venv ~/cms_venv
source ~/cms_venv/bin/activate
pip install -r requirements.txt
pip install .
```

---

### 4. 安裝系統環境（isolate）

```bash
sudo python3 prerequisites.py
```

出現提示：

* 若問「是否自動將你加入 cmsuser 群組」，
  想自己管理群組請選 **N**，然後：

  ```bash
  sudo usermod -a -G cmsuser $USER
  newgrp cmsuser
  ```

---

### 5. 建立資料庫

```bash
sudo -u postgres createuser --pwprompt cmsuser
sudo -u postgres createdb --owner=cmsuser cmsdb
sudo -u postgres psql -d cmsdb -c "ALTER SCHEMA public OWNER TO cmsuser"
sudo -u postgres psql -d cmsdb -c "GRANT SELECT ON pg_largeobject TO cmsuser"
```

---

### 6. 設定資料庫權限 (pg_hba.conf)

```bash
sudo -u postgres psql -Atc "SHOW hba_file"
# 假設輸出 /etc/postgresql/14/main/pg_hba.conf
sudo nano /etc/postgresql/14/main/pg_hba.conf
```

在檔案開頭加上：

```
host    cmsdb   cmsuser   127.0.0.1/32   md5
host    cmsdb   cmsuser   ::1/128        md5
```

然後重新載入設定：

```bash
sudo systemctl reload postgresql
```

---

### 7. 複製設定檔

```bash
sudo cp ~/cms/config/cms.conf.sample /usr/local/etc/cms.conf
sudo cp ~/cms/config/cms.ranking.conf.sample /usr/local/etc/cms.ranking.conf
```

編輯 `/usr/local/etc/cms.conf`：

```bash
sudo nano /usr/local/etc/cms.conf
```

修改資料庫連線資訊：

```
"database": "postgresql+psycopg2://cmsuser:<你的密碼>@127.0.0.1:5432/cmsdb"
```

---

### 8. 初始化資料庫與建立管理員

```bash
source ~/cms_venv/bin/activate
cmsInitDB
cmsAddAdmin admin cmsAdminWebServer
```
