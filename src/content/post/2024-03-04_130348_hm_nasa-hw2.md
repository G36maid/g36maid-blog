## 為什麼沒有完成 symlink file 的功能

在比較檔案或目錄的過程中，我們使用了 `diff` 命令來比較檔案內容，。然而，`diff` 在處理符號連結（symlink）檔案時的表現可能會有一些限制。

1. **diff 命令**：`diff` 主要用於比較文本檔案的差異，對於二進位文件或符號連結，可能無法提供適切的比較結果。

由於 Bash 腳本使用這這個命令進行比較，對於符號連結，它可能無法提供預期的結果。如果需要比較符號連結的目標文件，可以使用 `readlink` 命令取得符號連結指向的實際路徑，然後再進行比較。這需要對腳本進行進一步修改以支援這種情況。

## 使用到的 Bash 腳本知識

### 比較檔案內容 (compare_files)

1. **diff 命令**: 用於比較檔案內容的基本命令，`diff -d` 用於生成差異報告。
2. **grep 命令**: 用於搜尋 diff 輸出中的特定字元。
3. **wc 命令**: 用於計算行數，`wc -l` 用於計算行的數量。

### 比較目錄內容 (compare_directories)

4. **find 命令**: 用於搜尋目錄中的檔案。
5. **sed 命令**: 用於替換檔案路徑中的目錄部分。
6. **sort 命令**: 用於排序檔案列表。
7. **comm 命令**: 用於比較兩個已排序檔案列表的行。

### 選項解析及輸出格式化

8. **getopts**: 用於解析 Bash 腳本的命令列選項。
9. **echo 命令**: 用於輸出訊息，`echo -n` 用於輸出不換行。
10. **if-else 條件語句**: 用於實現不同的選項判斷和流程控制。
11. **mktemp 命令**: 用於生成臨時檔案。

### 正則表達式

12. **正則表達式**: 用於匹配檔案名稱，`grep` 中使用了正則表達式來過濾檔案。
13. **判斷檔案是否隱藏**: 正則表達式 `.*` 用於匹配隱藏檔案。

### 選項處理及錯誤處理

14. **usage 函式**: 用於顯示腳本的使用說明。
15. **選項解析**: 使用 `getopts` 解析命令列選項。
16. **if-else 條件語句**: 用於處理不同選項的情況。
17. **錯誤處理**: 使用 `usage` 函式處理不正確的使用方式。

### 檔案處理及排序

18. **文件路徑處理**: 使用 `sed` 分割檔案路徑，`grep` 過濾檔案，`cut` 提取特定部分。
19. **排序**: 使用 `sort` 對檔案列表進行排序。

### 迴圈及條件判斷

20. **迴圈**: 使用 `for` 迴圈遍歷檔案列表。
21. **條件判斷**: 使用 `if-else` 判斷檔案是否符合特定條件。

### 文件操作

22. **mktemp 命令**: 用於生成臨時檔案。
23. **rm 命令**: 用於刪除臨時檔案。
