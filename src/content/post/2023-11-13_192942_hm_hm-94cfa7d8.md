# Data Structure

## 佇列 Queue

### 概念
像是排隊結帳一樣，先排進隊伍中的，會在櫃台空下來時先出來結帳，
按照進入佇列的順序被移出佇列。
### 操作 Operations
佇列（queue）支援以下操作

* enqueue：將一筆資料加入 queue 中，排在最後面
* dequeue：將排在最前面的資料移出 queue 中
不允許將資料插入於隊伍最後面以外的地方，也不允許非隊伍最前頭以外的資料移出。


## 堆疊 Stack

### 概念
概念上像是把牛排一片一片疊起來，每次只能將最上面的牛排拿走。

例如函數的呼叫或是計算四則運算都是Stack的例子。

### 操作 Operations

堆疊（stack）支援以下操作：

* push：將資料疊至 stack 最上面
* pop：拿走 stack 最上面的資料

沒辦法動非最上面的資料，也沒辦法將新的資料插入至最上面以外的地方。
