## 題 5.2：

本題要求求出連桿 $\theta_3$ 的角度及滑塊 B 點的座標 $r_1$。

### 1. 建立方程式

曲柄滑塊四連桿組的位置向量迴路方程式為 $R_2 - R_3 - R_1 = 0$，以複數向量表示為 (5.10) 式：
$$r_2 e^{j\theta_2} - r_3 e^{j\theta_3} - r_1 e^{j\theta_1} = 0 \quad \text{(5.10)}$$

由於滑塊沿 X 軸移動，因此設定 $\theta_1 = 0^\circ$。將上式展開為實部和虛部聯立方程式：

*   **虛部 (Y 分量，用於求解 $\theta_3$):**
    $$r_2 \sin \theta_2 - r_3 \sin \theta_3 = 0 \quad \text{(5.11d)}$$
*   **實部 (X 分量，用於求解 $r_1$):**
    $$r_2 \cos \theta_2 - r_3 \cos \theta_3 - r_1 = 0 \quad \text{(5.11c)}$$

根據 (5.11d) 式，$\theta_3$ 可表示為 (5.11e)：
$$\theta_3 = \arcsin\left(\frac{r_2 \sin \theta_2}{r_3}\right) \quad \text{(5.11e)}$$
然後 $r_1$ 可由 (5.11c) 式計算得到。

### 2. 解

根據上述向量迴路法 (5.32) 以及 (5.34)~(5.39) 方式（註：此處應指位置分析 (5.11c)~(5.11f)），代入參數可得結果：

*   **當輸入角度 $\mathbf{\theta_2 = 30^\circ}$ 時:**
    *   計算求得 $\theta_3 = \mathbf{168^\circ}$。
    *   計算求得 $r_1 = \mathbf{33.80}$。
    *   B 點座標為 $(\mathbf{80.33}, \mathbf{0})$。

*   **當輸入角度 $\mathbf{\theta_2 = 120^\circ}$ 時:**
    *   計算求得 $\theta_3 = \mathbf{158.8^\circ}$。
    *   計算求得 $r_1 = \mathbf{45.43}$。
    *   B 點座標為 $(\mathbf{43.45}, \mathbf{0})$。

## 習題 5.6：銷接頭四連桿組之位置分析

本題針對銷接頭四連桿組（表 5.1 列 1）進行分析，目標是求出 $\theta_3$ 和 $\theta_4$ 的兩組可能角度。

### 1. 建立方程式

銷接頭四連桿組的位置向量迴路方程式為 $R_2 + R_3 - R_4 - R_1 = 0$，以複數向量表示為 (5.4)：
$$r_2 e^{j\theta_2} + r_3 e^{j\theta_3} - r_4 e^{j\theta_4} - r_1 e^{j\theta_1} = 0 \quad \text{(5.4)}$$

將上式展開為實部和虛部聯立方程式 (設定 $\theta_1 = 0^\circ$)：
*   **實部 (X 分量):**
    $$r_2 \cos \theta_2 + r_3 \cos \theta_3 - r_4 \cos \theta_4 - r_1 = 0 \quad \text{(5.6a)}$$
*   **虛部 (Y 分量):**
    $$r_2 \sin \theta_2 + r_3 \sin \theta_3 - r_4 \sin \theta_4 = 0 \quad \text{(5.6b)}$$

### 2. 解

**已知參數 (列 1):** $r_1 = 6, r_2 = 2, r_3 = 7, r_4 = 9, \theta_2 = 45^\circ$。

**代入複數向量方程式:**
$$2(\cos 45^\circ + j \sin 45^\circ) + 7(\cos \theta_3 + j \sin \theta_3) - 9(\cos \theta_4 + j \sin \theta_4) - 6(\cos 0^\circ + j \sin 0^\circ) = 0 \quad \text{}$$

**展開並聯立實部與虛部:**
*   **實部：** $2 \cos 45^\circ + 7 \cos \theta_3 - 9 \cos \theta_4 - 6 = 0$
*   **虛部：** $2 \sin 45^\circ + 7 \sin \theta_3 - 9 \sin \theta_4 = 0$

**求解結果：** 根據方程，聯立求解這兩個非線性方程式，可得到兩組解：
*   **第一組解：** $(\theta_{31}, \theta_{41}) = (\mathbf{81^\circ}, \mathbf{112^\circ})$。
*   **第二組解：** $(\theta_{32}, \theta_{42}) = (\mathbf{-115^\circ}, \mathbf{-147^\circ})$。

## 習題 5.9：曲柄滑塊機構之速度分析

本題要求利用向量迴路法，求出滑塊 $V_C$ 的速度向量（即 $\dot{r}_1$）和角速度 $\omega_4$。

### 1. 建立方程式

曲柄滑塊機構的速度方程式是將位置向量方程式 (5.32) 對時間微分得到的 (5.33)：
$$j r_2 \omega_2 e^{j\theta_2} - j r_3 \omega_3 e^{j\theta_3} - \dot{r}_1 e^{j\theta_1} = 0 \quad \text{(5.33)}$$
其中 $\omega_3$ 是連桿 3 的角速度，$\dot{r}_1$ 是滑塊的速度 $V_C$。

將 (5.33) 式分為實部和虛部聯立方程式 (設定 $\theta_1 = 0^\circ$)：
*   **虛部 (用於求解 $\omega_3$):**
    $$r_2 \omega_2 \cos \theta_2 - r_3 \omega_3 \cos \theta_3 = 0 \quad \text{(5.34b)}$$
*   **實部 (用於求解 $\dot{r}_1$):**
    $$r_2 \omega_2 \sin \theta_2 - r_3 \omega_3 \sin \theta_3 + \dot{r}_1 = 0 \quad \text{(5.34a)}$$

### 2. 解

**已知條件:** $\omega_2 = 150 \text{ r/min}$。

**角速度轉換:**
$$\omega_2 = 150 \text{ r/min} \times \frac{2\pi}{60} \approx \mathbf{7.15 \text{ rad/s}}$$

根據方程中的片段計算，聯立求解 (5.34a) 和 (5.34b) 式，得到 $\omega_3$（在方程中記為 $\omega_4$）和滑塊速度 $\dot{r}_1$：

*   **角速度 $\mathbf{\omega_4}$：** $\mathbf{1.38 \text{ rad/s}}$。
*   **滑塊速度向量 $\mathbf{V_C}$ ($\dot{r}_1$):**
    *   大小 (Magnitude): $\mathbf{34.6 \text{ mm/s}}$。
    *   方向 (Angle): $\mathbf{205^\circ}$。
