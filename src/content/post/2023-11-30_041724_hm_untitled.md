A "strongly connected component (SCC)" in a directed graph means that every vertex in the component is reachable for any other vertices in the same component.

In this problem, you need to determine how many pairs of vertices are there, which can reach each other.

Input
For each test case, there would be several lines representing a directed graph:

The first line contains two integers 
N and M
, representing the number of vertex and the number of edge respectively. Then, there would be M
 lines; each line has two integers u,v
 representing an edge from vertex u
 to vertex v
