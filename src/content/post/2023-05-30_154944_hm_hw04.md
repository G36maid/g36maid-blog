## 06
這段程式碼是一個C語言的程式，並使用了預處理器指令 #define 和 printf 函式。

程式中的 #define 指令用來定義了一個宏（macro） Peval，它將參數 cmd 以字串的形式傳遞給 printf 函式。換句話說，Peval(cmd) 會展開為 printf( #cmd ": %g\n", cmd );，其中 #cmd 會將 cmd 轉換成字串。

在 main 函式中，首先宣告了一個指向 double 型別的指標 plist，並將它初始化為一個匿名的 double 陣列 {1, 2, 3}。接著宣告了另一個 double 陣列 list，並初始化為 {1, 2, 3}。

接下來，程式使用了 Peval 宏來輸出兩個表達式的值。第一個表達式是 sizeof( plist ) / ( sizeof( double ) + 0.0 )，它計算 plist 的大小除以 double 型別的大小再加上 0.0。第二個表達式是 sizeof( list ) / ( sizeof( double ) + 0.0 )，它計算 list 的大小除以 double 型別的大小再加上 0.0。

最後，程式返回 0，表示執行成功結束。

輸出結果為：


```=
sizeof( plist ) / ( sizeof( double ) + 0.0 ): 1
sizeof( list ) / ( sizeof( double ) + 0.0 ): 3
```
這些結果是由於 sizeof 運算子返回一個物件或型別的大小（以位元組為單位）。在這個程式中，plist 是一個指向 double 型別的指標，所以 sizeof( plist ) 的結果是指標的大小，通常是 4 或 8 個位元組，取決於所使用的平台。而 sizeof( double ) 則是 double 型別的大小，通常是 8 個位元組。

因此，第一個表達式 sizeof( plist ) / ( sizeof( double ) + 0.0 ) 的結果是指標的大小除以 double 的大小再加上 0.0，而這個計算結果為 1。

第二個表達式 sizeof( list ) / ( sizeof( double ) + 0.0 ) 的結果則是 list 陣列的大小除以 double 的大小再加上 0.0。由於 list 陣列中有 3 個元素，每個元素佔用 double 型別的大小，所以 sizeof( list ) 的結果是 3 乘上 double 的大小，也就是 3 乘上 8，即 24 個位元組。因此，這個表達式的結果是 24 除以 double 的大小再加上 0.0，結果為 3。

## 07

Could you please explain how this command can determine the file type?
原理就是讀取文件的前1024個字節
然後根據magic(etc/magic)或(/usr/share/misc/magic)
裡面的規則分析出檔案種類


magic文件內容格式 文件中的每行都指定了一個規則測試去檢驗文件類型，這個規則由4個域指定：
offset：指定由文件起始的第幾個byte開始檢驗。 
     type：要進行檢驗的數據類型，即由offset那個byte開始的那個數據類型是什麼。具體有哪些數據類型，可以參照magic(5)。常用的數據類型有 
1. byte：一個byte的值 
1. short：兩個byte的值 
1. long：四個byte的值 
1. string：字符串。 

test：檢驗值。用於檢驗offset下的type是否是這個test值。使用C語言的數值或字符表示形式。 
message：用於顯示檢驗結果的信息顯示 

如果type為數值類型，那麼其後面可添加&value，表示先與後面的test值進行'與'操作，再進行比較。

如果type為字符串類型，則其後可跟/[Bbc]*，/b表示忽略空格，/c表示忽略字母大小寫。 

如果test的值為數值類型，可以數值前添加＝，<，>，&，^，~，分別表示相等、小於、大於、與操作、異或操作、取反操作。

如果test的值為字符串類型，可以在其前添加＝、<、>。
