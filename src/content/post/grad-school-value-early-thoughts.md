2025 年九月底的深夜貼文。當時的我：機電系大四，白天在一家公司的軟體團隊實習，晚上在想一件很俗的事——學歷到底買不買得到東西。

「為了一堂課延畢真的很蠢」是貼文的第一行。但把這句話拆開看，蠢的部分沒有表面那麼簡單。延畢真正貴的地方是一整年的時間：學分費反而是小事，麻煩的是那一年的身份停在「還在校內」，沒有完整的工作年資，履歷上多一行還要另外解釋。可是反過來想，那一年如果拿去修資工的課、做專題、寫 side project，也未必是純浪費。當時我把「蠢」掛在嘴邊，其實是因為還沒想清楚那一年的用途，只先看到了要付的代價。

實習這條路給我的東西很具體：進到真的產品程式碼裡，看 code review 怎麼跑、看 release 怎麼出、看工程師怎麼跟產品端吵一架然後把功能做出來。這些在課堂上用幾學分都換不到。實習期間寫的紀錄（[實習心得](/blog/moxa-internship-report/)）回頭看還是覺得那段時間密度很高。不過實習也讓我看清楚一件事：實習生做的再多，那張票終究是「先進來看看」等級，要跳去更好的公司，對方看的是你手上的籌碼——學歷、作品、經歷，總得有一樣能過第一關。

所以問題變成：碩士這兩年，對我這種實作派到底買到什麼？直接講結論的話，我當時的答案是「幾乎只剩誘因」。論文要解的問題跟業界要解的問題常常不同軸，兩年裡練出來的技術能力，說不定自己寫 side project 也練得出來。剩下能說服我的，就只有薪水上限、某些公司某些職等的硬門檻、獵人頭時的篩選條件。這些聽起來很現實，但它們真的存在，而且沒有人能給我一張表，告訴我兩年碩士到底換到多少溢價。問了幾個學長姐，答案南北兩極：有人說後悔沒早點出來工作，有人說當年沒讀現在卡在某個職等上不去。每個人的樣本都只有一份，包括我。

我原本的理論很簡單：只有第一個工作會看你的學歷。所以策略是——用現在手上的東西擠進一家還行的公司，做一兩年，之後靠經歷跳槽，學歷那欄在履歷上的比重就慢慢淡掉。去更好的公司繼續跳，不就好了？這個理論寫在 FB 上很順，但多想幾步就有洞。第一，「擠進還行的公司」這步本身是賭注，不靠碩士能不能過篩，沒試過誰都不知道。第二，跳槽的時候學歷欄還是在，只是比重變低，低到什麼程度沒有人說得準。第三，這條路假設我兩年後還想走同一種工作——大四的我對自己兩年後的判斷力，其實沒什麼信心。

寫到這裡，每個論點都還是假設，沒有一個是我驗證過的。我還在思考。貼文的最後一行是這樣，現在也是這樣。只是把選項一條條攤開來寫，好像比較不會半夜一直轉這個念頭。

## 2026-11 update

一年後的後續：我最後選了繼續升學，走推甄，116 學年度正在申請中（機電四 + 資工雙主修，A 進 B 出）。當時那套「只有第一個工作看學歷」的理論，現在回頭看一半成立：市場確實越來越看實際做過的東西，但門檻沒有消失，只是換了形式——研究所除了文憑，還有兩年被允許專心做技術的時間，和履歷上多一個能講的題目。延畢那堂課的糾結倒是消失得最快：決定升學之後，那一年本來就要讀，機會成本的算法整個重寫。選擇還在進行中，錄取與否、兩年後會怎麼看這個決定，都還沒驗證。
