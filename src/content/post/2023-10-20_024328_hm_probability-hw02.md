### (1)
define:
E(X) = Σ[x * P(X = x)],


E(X + Y) = Σ[(x + y) * P(X = x and Y = y)],

Now, we can rewrite the joint probability as a product of the individual probabilities:

P(X = x and Y = y) = P(X = x) * P(Y = y).

separate the summation into two parts.

E(X + Y) = ∑[(x + y) * P(X = x) * P(Y = y)].

E(X + Y) = ∑[x * P(X = x) * P(Y = y)] + ∑[y * P(X = x) * P(Y = y)].

E(X + Y) = E(X) + E(Y).

### (2)
defined:
Var(X) = E[(X - E(X))^2],

E(X^2) = Var(X) + (E(X))^2.
E(X^2) = ∑[x^2 * P(X = x)],

rewrite E[(X - E(X))^2] using the properties of expected values:
Var(X) = E[(X - E(X))^2] = E(X^2 - 2X*E(X) + (E(X))^2).
Var(X) = E(X^2) - 2E(X*E(X)) + (E(X))^2。

use the linearity of the expected value to separate the second term:
Var(X) = E(X^2) - 2E(X)E(X) + (E(X))^2.

Simplify:
Var(X) = E(X^2) - 2(E(X))^2 + (E(X))^2.

combine:
Var(X) = E(X^2) - (E(X))^2.
Var(X) + (E(X))^2 = E(X^2) - (E(X))^2 + (E(X))^2.

Simplify:
Var(X) + (E(X))^2 = E(X^2).

So, shown that:
E(X^2) = Var(X) + (E(X))^2.
