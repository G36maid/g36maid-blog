# C Programming TA

## Goals
- Learn how to program in C.
- Learn how to survive in Linux.

## Tools
- **Linux (Ubuntu in Teacher's Computer)**
  - If you are not familiar with Linux, maybe you can follow the following tutorial: [Unix Tutorial for Beginners](https://www.tutorialspoint.com/unix/index.htm)
  - You can install Linux in virtual machines:
    - [Oracle VM VirtualBox](https://www.virtualbox.org/)
    - [VMware Workstation Player](https://www.vmware.com/products/workstation-player.html)
  - **How to install VirtualBox and an Ubuntu virtual machine?**
    - Do not ask me for help, or I will help you to flush your disk and reinstall Linux for you!
  - **Compiler:** GCC, the GNU Compiler Collection

- **Make**
  - [GNU Make](https://www.gnu.org/software/make/)
  - [Makefile Tutorial](https://makefiletutorial.com/)
  - [Makefile Slide](https://www.slideshare.net/MorganThompson2/makefiles)
  - In this class, I will use Ubuntu. Actually, any Linux distribution should be fine. If you have any platform problems, feel free to contact our TAs.
  - At least, I will show you how to solve problems in Ubuntu.
  - You can install the development tool by the following command:
    ```sh
    $ sudo apt-get install build-essential
    ```
