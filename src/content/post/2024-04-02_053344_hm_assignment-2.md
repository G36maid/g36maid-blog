## 2. Agent Functions vs. Agent Programs (20 pts)
Agent functions refer to the mapping from percept histories to actions, whereas agent programs are implementations of these functions.
a. Yes, there can be more than one agent program that implements a given agent function. For example, different algorithms or methods can achieve the same behavior. For instance, both a decision tree and a neural network can classify images effectively.
b. Yes, there are agent functions that cannot be implemented by any agent program. For example, if the environment is non-deterministic or if the agent's actions have no effect on the environment, certain functions cannot be realized.
c. No, given a fixed machine architecture, not every agent program implements exactly one agent function. Different programs can achieve the same function, and one program can implement multiple functions.

## 3. PEAS Descriptions (30 pts)
a. Playing soccer  
   - **Performance Measure:** Winning the game, scoring goals, fair play
   - **Environment:** Soccer field, players, referee, spectators
   - **Actuators:** Legs, feet, body movements
   - **Sensors:** Eyes, ears, skin (for touch)
   
   Characteristics:
   - **Fully Observable:** Generally yes, although some parts of the field might be obscured.
   - **Deterministic:** Largely yes, except for occasional referee decisions or unpredictable ball movements.
   - **Episodic:** Yes, each game can be considered an episode.
   - **Static:** No, the positions of players and the ball change dynamically.
   - **Discrete:** No, movements and actions can be continuous.

b. Playing a tennis match  
   - **Performance Measure:** Winning points, winning sets, following rules
   - **Environment:** Tennis court, net, racket, ball, opponent
   - **Actuators:** Arms, hands, racket
   - **Sensors:** Eyes, ears, skin
   
   Characteristics:
   - **Partially Observable:** Yes, especially regarding the opponent's intentions and movements.
   - **Deterministic:** Mostly yes, though external factors like wind can introduce uncertainty.
   - **Sequential:** Yes, each move influences subsequent ones.
   - **Dynamic:** Yes, the ball's trajectory changes constantly.
   - **Discrete:** Yes, actions like serving or hitting the ball are discrete.

c. Practicing tennis against a wall  
   - **Performance Measure:** Improving skills, accuracy, stamina
   - **Environment:** Tennis court, wall, racket, ball
   - **Actuators:** Arms, hands, racket
   - **Sensors:** Eyes, ears, skin
   
   Characteristics:
   - **Fully Observable:** Yes, as the agent can perceive the entire environment.
   - **Deterministic:** Mostly yes, as the agent controls its actions.
   - **Episodic:** Yes, each session can be considered an episode.
   - **Static:** Yes, the environment remains unchanged during practice.
   - **Discrete:** No, actions can be continuous.

d. Shopping for used AI books on the Internet  
   - **Performance Measure:** Finding desired books, getting good deals
   - **Environment:** Online marketplace, web browser, sellers, listings
   - **Actuators:** Mouse, keyboard
   - **Sensors:** Eyes, computer screen
   
   Characteristics:
   - **Partially Observable:** Yes, as the agent may not have complete information about all available listings.
   - **Stochastic:** Yes, prices and availability may change unpredictably.
   - **Sequential:** Yes, the agent may need to make multiple decisions before completing a purchase.
   - **Dynamic:** Yes, the marketplace changes as listings are added or removed.
   - **Discrete:** Mostly yes, as actions like clicking or typing are discrete.

e. Bidding on an item at an auction  
   - **Performance Measure:** Winning desired items at reasonable prices
   - **Environment:** Online auction platform, other bidders, items for sale
   - **Actuators:** Mouse, keyboard
   - **Sensors:** Eyes, computer screen
   
   Characteristics:
   - **Partially Observable:** Yes, as the agent may not know other bidders' maximum bids.
   - **Stochastic:** Yes, bidding behaviors of other participants can be unpredictable.
   - **Sequential:** Yes, as the agent may revise its bids based on auction progress.
   - **Dynamic:** Yes, new items are added, and bids change over time.
   - **Discrete:** Mostly yes, as bidding actions are discrete.

## 4. Definitions (35 pts)
a. **Rationality:** Rationality refers to the ability of an agent to select actions that maximize its expected utility based on available information and its goals.
b. **Autonomy:** Autonomy refers to an agent's ability to operate independently without direct human intervention, making decisions and taking actions on its own.
c. **Reflex agent:** A reflex agent bases its actions solely on the current percept, without considering past percepts or future consequences.
d. **Model-based agent:** A model-based agent maintains an internal model of the environment, allowing it to plan and make decisions based on expected future states.
e. **Goal-based agent:** A goal-based agent selects actions based on its goals, striving to achieve desired states of the environment.
f. **Utility-based agent:** A utility-based agent evaluates actions based on their expected outcomes and selects the action with the highest utility, aiming to maximize overall utility.
g. **Learning agent:** A learning agent improves its performance over time by learning from experience, adjusting its behavior based on feedback from the environment.
