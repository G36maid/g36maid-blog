to each other in six linear spots labeled 1 to 6, one to a spots. Baby needs to line

Formulate this problem as a CSP by list the following:
• variables (5 pts),

Encode unary constraints as a constraint rather than pruning the domain. (No need
to solve the problem, just provide variables, domains, and constraints.)

To formulate this problem as a Constraint Satisfaction Problem (CSP), we need to identify the variables, their domains, and the constraints that must be satisfied. 

<div style="page-break-after:always;"></div>

### Variables:
1. $( X_1 )$: The occupant of spot 1.
2. $( X_2 )$: The occupant of spot 2.
3. $( X_3 )$: The occupant of spot 3.
4. $( X_4 )$: The occupant of spot 4.

### Domains:
Each variable can take any value from the set \{Mom, Dad, Baby, Student, Teacher, Guide\}. However, due to constraints, the domains will be adjusted accordingly:

domain = $\{Mom, Dad, Baby, Student, Teacher, Guide\}$

<div style="page-break-after:always;"></div>

$(X_1 = \text{Guide})$ or $(X_6 = \text{Guide})$

## 2. define the following terms in your own words:
### a. constraint (2pts)

A constraint is a restriction or condition that variables in a problem must satisfy. In the context of constraint satisfaction problems, constraints define the allowable combinations of values for a set of variables. 

### b. commutativity (2pts)
Commutativity is a property of certain operations where the order in which the operations are performed does not affect the final result. For instance, in arithmetic, addition and multiplication are commutative

<div style="page-break-after:always;"></div>

### c. backtracking search (2pts)
Backtracking search is an algorithm to slove CSP and other combinatorial problems.

It involves exploring possible solutions incrementally, one variable at a time, and backtracking (reverting to a previous step) when a constraint is violated. This process continues until a solution is found or all possibilities have been exhausted

### d. arc consistency (2pts)
A variable in a CSP is arc-consistent if every value in its domain satisfies the variable’s
binary constraints.

#### exapmle :
a variable $X$ is arc consistent with another variable $Y$ if every value in the domain of 
$X$ has a corresponding value in the domain of $Y$ that satisfies the binary constraint between 
$X$ and $Y$. 

<div style="page-break-after:always;"></div>

### e. backjumping (2pts)
Backjumping is an enhancement to the basic backtracking search that allows the algorithm to skip back more than one level when a constraint violation occurs. Instead of reverting to the immediately preceding variable, backjumping identifies the most recent variable assignment that is likely responsible for the failure and jumps back to that point.

$(P_1 ∧ P_2 ∧ \cdots ∧ P_m) ⇒ Q \equiv ¬(P_1 ∧ P_2 ∧ \cdots ∧ P_m) ∨ Q$

#### 2

apply De Morgan's laws to the expression$¬(P_1 ∧ P_2 ∧ \cdots ∧ P_m)$:

$¬(P_1 ∧ P_2 ∧ \cdots ∧ P_m) \equiv ¬P_1 ∨ ¬P_2 ∨ \cdots ∨ ¬P_m$

#### 3

$¬(P_1 ∧ P_2 ∧ \cdots ∧ P_m) ∨ Q \equiv (¬P_1 ∨ ¬P_2 ∨ \cdots ∨ ¬P_m) ∨ Q$

#### 4

The expression$(¬P_1 ∨ ¬P_2 ∨ \cdots ∨ ¬P_m) ∨ Q$ simplifies directly to the original clause:

$(¬P_1 ∨ ¬P_2 ∨ \cdots ∨ ¬P_m ∨ Q)$

We have shown that:

$(P_1 ∧ P_2 ∧ \cdots ∧ P_m) ⇒ Q \equiv (¬P_1 ∨ ¬P_2 ∨ \cdots ∨ ¬P_m ∨ Q)$

### 3.2

To show that every clause (regardless of the number of positive literals) can be written in the form $(P_1 ∧ \cdots ∧ P_m) ⇒ (Q_1 ∨ \cdots ∨ Q_n)$, where the $P_i$ and $Q_j$ are proposition symbols, we need to demonstrate that any clause can be transformed into this implicative normal form (INF). 

### Understanding Clauses and Implicative Normal Form

The general form of a clause is:

$L_1 ∨ L_2 ∨ \cdots ∨ L_k$

where each $L_i$ is either a positive literal $P_i$ or a negative literal $¬P_i$.

The **implicative normal form** (INF) is an expression of the form:

$(P_1 ∧ P_2 ∧ \cdots ∧ P_m) ⇒ (Q_1 ∨ Q_2 ∨ \cdots ∨ Q_n)$

where $P_i$ and $Q_j$ are proposition symbols.

Consider a general clause $C$ of the form:

$L_1 ∨ L_2 ∨ \cdots ∨ L_k$

We need to transform this into an expression of the form:

$(P_1 ∧ P_2 ∧ \cdots ∧ P_m) ⇒ (Q_1 ∨ Q_2 ∨ \cdots ∨ Q_n)$


<div style="page-break-after:always;"></div>

#### Transformation

1. **Identify Positive and Negative Literals**:
   - Let $L_1, L_2, \ldots, L_a$ be the positive literals $P_1, P_2, \ldots, P_a$.
   - Let $L_{a+1}, L_{a+2}, \ldots, L_k$ be the negative literals $¬P_{a+1}, ¬P_{a+2}, \ldots, ¬P_k$.

2. **Rewrite Negative Literals**:
   - Convert each negative literal $¬P_{a+i}$ into a positive implication $P_{a+i} ⇒ \bot$ where $\bot$ (false) can be considered as $Q$.
   - For our purpose, we can directly use the equivalence $¬P_{a+i}$ which is equivalent to $P_{a+i} ⇒ Q$ if $Q$ represents false.

3. **Construct the Implicative Form**:
   - Rewrite the clause $L_1 ∨ L_2 ∨ \cdots ∨ L_k$ as $(¬P_1) ∨ (¬P_2) ∨ \cdots ∨ (¬P_a) ∨ P_{a+1} ∨ \cdots ∨ P_k$.
   - Use the logical equivalence that $¬A \equiv A ⇒ Q$ where $Q$ represents any disjunction of $Q_j$.

4. **Form the Implication**:
   - Convert $L_1 ∨ L_2 ∨ \cdots ∨ L_k$ into $(P_1 ∧ P_2 ∧ \cdots ∧ P_a) ⇒ (P_{a+1} ∨ P_{a+2} ∨ \cdots ∨ P_k)$.

This form matches the structure $(P_1 ∧ \cdots ∧ P_m) ⇒ (Q_1 ∨ \cdots ∨ Q_n)$

To determine the correct representation of the assertion "a person who is radical $R$ is electable $E$ if he/she is conservative $C$, but otherwise is not electable," we need to carefully analyze the logical structure of the statement. Let's break it down and then evaluate each option.

### Analyzing the Assertion

The assertion can be divided into two parts:

1. **If a person is radical and conservative, then they are electable**:
   - This can be represented as: $R \land C \Rightarrow E$

2. **If a person is radical and not conservative, then they are not electable**:
   - This can be represented as: $R \land \neg C \Rightarrow \neg E$

Combining these two conditions, we have:
- $R \Rightarrow ((C \Rightarrow E) \land (\neg C \Rightarrow \neg E))$


<div style="page-break-after:always;"></div>

#### Option (a): $(R \land E) \Leftrightarrow C$
- The left side $(R \land E)$ means the person is radical and electable.
- The right side $C$ means the person is conservative.
- Thus, it claims that $R \land E$ if and only if $C$.

However, this doesn't fully capture the second part of the assertion, which is the person is not electable if they are not conservative. This option doesn't directly imply $R \land \neg C \Rightarrow \neg E$.

#### Option (b): $R \Rightarrow (E \Leftrightarrow C)$

- $R \Rightarrow (E \Leftrightarrow C)$ means if a person is radical, then they are electable if and only if they are conservative.
- This implies both $R \land C \Rightarrow E$ and $R \land \neg C \Rightarrow \neg E$.

This option correctly captures both parts of the assertion.

#### Option (c ): $R \Rightarrow ((C \Rightarrow E) \lor \neg E)$
- $C \Rightarrow E$ means if a person is conservative, they are electable.
- $\neg E$ means the person is not electable.
- However, $(C \Rightarrow E) \lor \neg E$ is logically equivalent to $\neg C \lor E \lor \neg E$, which simplifies to $\neg C \lor \text{true}$ (since $E \lor \neg E$ is always true), and hence just $\neg C \lor \text{true}$, which is always true.

This option simplifies to a tautology and does not capture the specific conditions of the assertion.

#### ANS
Given the analysis above, the correct representation of the assertion is B
 $R \Rightarrow (E \Leftrightarrow C)$

### 1
To solve this problem, we need to formulate it using a probability model. We'll use the given information to find the probability that an alien is friendly given that it arrives at night. 

### Solution

**1. Define Events:**
-  $F$ : The event that an alien is friendly.
-  $N$ : The event that an alien arrives at night.

**2. Given Probabilities:**
-  $P(F) = 0.75$  (75% of aliens are friendly).
-  $P(\text{not } F) = 0.25$  (25% of aliens are not friendly).
-  $P(N \mid F) = 0.10$  (10% of friendly aliens arrive at night, so 90% arrive during the day).
-  $P(N \mid \text{not } F) = 1.00$  (100% of unfriendly aliens arrive at night).

**3. Goal:**
- Find  $P(F \mid N)$ , the probability that an alien is friendly given that it arrives at night.

**4. Apply Bayes' Theorem:**
Bayes' Theorem states:
 $P(F \mid N) = \frac{P(N \mid F) P(F)}{P(N)}$ 

**5. Calculate  $P(N)$ :**
 $P(N) = P(N \mid F) P(F) + P(N \mid \text{not } F) P(\text{not } F)$ 
Substitute the given probabilities:
 $P(N) = (0.10)(0.75) + (1.00)(0.25)$ 
 $P(N) = 0.075 + 0.25$ 
 $P(N) = 0.325$ 

**6. Substitute into Bayes' Theorem:**
 $P(F \mid N) = \frac{(0.10)(0.75)}{0.325}$ 
 $P(F \mid N) = \frac{0.075}{0.325}$ 

**7. Simplify the Fraction:**
 $P(F \mid N) = \frac{75}{325}$ 
 $P(F \mid N) = \frac{15}{65}$ 
 $P(F \mid N) = \frac{3}{13}$

###  Solution

**1. Define Events:**

-  $B$ : The event that a monster lives in the basement.
-  $F$ : The event that a monster is fuzzy.

**2.  Probabilities:**
-  $P(A) = 0.5$  (half of all monsters live in attics).
-  $P(B) = 0.5$  (the rest live in basements).
-  $P(F) = 0.8$  (80% of all monsters are fuzzy).
    -  $P(F \mid A) = 1$  (all attic-living monsters are fuzzy).

- Find  $P(F \mid B)$ , the probability that a basement-living monster is fuzzy.

**3. Relationship :**
We know:
 $P(F) = P(F \mid A) P(A) + P(F \mid B) P(B)$ 

Substitute the known probabilities:
 $0.8 = (1)(0.5) + P(F \mid B)(0.5)$ 

**4. Solve f $P(F \mid B)$ :**
 $0.8 = 0.5 + 0.5 P(F \mid B)$ 
 $0.8 - 0.5 = 0.5 P(F \mid B)$ 
 $0.3 = 0.5 P(F \mid B)$ 
 $P(F \mid B) = \frac{0.3}{0.5}$ 
 $P(F \mid B) = 0.6$
