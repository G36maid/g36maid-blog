To count the total number of inversions in array B using the Magic Counter C, we can utilize the concept of Merge Sort with some modifications. Here's the algorithm in pseudocode:
```=
function countInversions(B, K):
    // Base case: if the array has only one element, no inversions exist
    if length(B) <= 1:
        return 0

    // Split the array into two halves
    mid = length(B) / 2
    left = B[0:mid]
    right = B[mid:]

    // Recursively count inversions in the left and right halves
    inversions = countInversions(left, K) + countInversions(right, K)

    // Merge the sorted halves while counting inversions
    i = j = 0
    while i < length(left) and j < length(right):
        if left[i] > right[j]:
            // An inversion is found
            inversions += sum(K) - sum(right[j])

            // Increment the count of right[j] in the Magic Counter
            insert(right[j])

            j += 1
        else:
            // No inversion, proceed with merging
            insert(left[i])
            i += 1

    // Process remaining elements in the left half, if any
    while i < length(left):
        insert(left[i])
        i += 1

    // Process remaining elements in the right half, if any
    while j < length(right):
        // Each element in the right half is an inversion with all elements in the left half
        inversions += sum(K) - sum(right[j])
        insert(right[j])
        j += 1

    return inversions

```
In this algorithm, we use the Magic Counter C to maintain a count of the occurrences of each element encountered. Whenever an inversion is found, we calculate the number of inversions using the sum of occurrences in the Magic Counter.

The algorithm splits the array recursively into smaller halves until the base case is reached (i.e., when the array has only one element). Then, it merges the sorted halves while counting inversions. The counts in the Magic Counter are updated accordingly during the merging process.

The runtime complexity of this algorithm is O(N log K), where N is the length of array B and K is the range of values. The logarithmic complexity arises from the operations on the Magic Counter, which take O(log M) time, where M represents the maximum value inserted into the Magic Counter.

Here's the algorithm to calculate the number of substrings:

1. Initialize a variable count to 0, which will keep track of the number of substrings.
1. Initialize two pointers, start and end, both initially pointing to the start of the string.
1. Start iterating over the string with the end pointer until it reaches the end of the string.
1. For each character encountered at the end pointer, check if it is equal to the character σ.
1. If it is equal to σ, move the start pointer to the position right after the character σ.
1. If it is not equal to σ, increment the count by the difference between end and start plus 1. This accounts for all the substrings ending at the current position that do not contain σ.
1. Repeat steps 3-4 until the end pointer reaches the end of the string.
1. After the iteration completes, add the remaining substrings from the last start position to the end of the string to the count. This accounts for all the substrings that end at the last position and do not contain σ.
1. Return the final value of count.

This algorithm runs in O(N) time complexity because it iterates over the string once, performing constant-time operations at each step.
