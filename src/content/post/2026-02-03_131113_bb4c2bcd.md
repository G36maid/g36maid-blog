用了整整一個月的 oh-my-opencode
我的開發流程發生了以下變化

設定良好的 AGENTS.md (使用 /init 並手動修改一下)
用一個小的 agents 處理所有探索，調用所有 mcp 
Exa (Web Search)
Context7 (Official Documentation)
Grep.app (GitHub Code Search)
給我文檔及其他人使用的最佳實踐
另一個小 agents 用 rg 分析當前程式/文件並設定最小目標(靶心)

然後最貴最強的主 agents 配合 lsp + AGENTS.md +  skills直接 one shot 並完成測試的感覺真的超爽

當然代價就是如果沒有好好設定好 subagent 的 provider, 設定成免費或是較便宜的 model
那麼 oh-my-opencode 就真的是 token burner
