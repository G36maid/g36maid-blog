## 1. 配置 Hexo

### 步驟 1：安裝 Node.js 和 Git
確保你的電腦上已經安裝了 Node.js 和 Git。你可以在它們的官方網站上下載並安裝。

```
sudo apt-get install git-core
```
```
curl -sL https://deb.nodesource.com/setup_14.x | sudo bash -
sudo apt install -y nodejs
```
### 步驟 2：安裝 Hexo
在命令行中執行以下命令安裝 Hexo：

```
npm install -g hexo-cli
```

### 步驟 3：創建一個新的 Hexo 網站
在命令行中執行以下命令創建一個新的 Hexo 網站：

```
hexo init myblog
cd myblog
npm install
```

### 步驟 4：啟動本地服務器
執行以下命令以在本地啟動 Hexo 服務器：

```
hexo server
```

現在你可以在瀏覽器中打開 `http://localhost:4000` 查看你的網站。

## 2. Markdown 編寫

Hexo 使用 Markdown 來撰寫文章。在 `source/_posts` 目錄中，你可以找到示例文章 `hello-world.md`。使用 Markdown 語法編寫你的文章。
當然，我可以提供一個更詳細的 Markdown 編寫教學，特別針對從未使用過 Markdown 的學生。讓我們來深入了解 Markdown 的基礎知識：

### Markdown 是什麼？

Markdown 是一種輕量級的標記語言，用於編寫格式化的文本，以便於轉換為HTML等其他格式。它通常用於撰寫網頁內容、Readme 文件、網誌文章等。

### 基本語法

#### 標題

在 Markdown 中，你可以使用 `#` 來標記標題，`#` 的數量代表標題的級別，例如：

```markdown
# 一級標題
## 二級標題
### 三級標題
```

#### 文字格式

你可以使用下列方式來調整文字的格式：

- **粗體**: 使用 `**` 或 `__` 包圍文字來顯示粗體，例如：`**這是粗體文字**`。
- *斜體*: 使用 `*` 或 `_` 包圍文字來顯示斜體，例如：`*這是斜體文字*`。
- ~~刪除線~~: 使用 `~~` 包圍文字來顯示刪除線，例如：`~~這是刪除線文字~~`。

#### 列表

Markdown 支持有序列表和無序列表：

- **無序列表** 使用 `-`、`+` 或 `*` 作為項目標記，例如：
  ```markdown
  - 項目1
  - 項目2
  - 項目3
  ```

- **有序列表** 使用數字加上英文句點作為項目標記，例如：
  ```markdown
  1. 第一項
  2. 第二項
  3. 第三項
  ```

#### 鏈接和圖片

你可以使用 `[顯示文字](連結)` 來添加超鏈接，例如：`[OpenAI](https://openai.com)`。

要添加圖片，使用 `![圖片描述](圖片連結)`，例如：`![OpenAI Logo](https://openai.com/assets/logo-d5c8e8d92bca0b3ad88b6ce56167b88f1fc66b1765700722ff0b20a08d0d1ee0.png)`。

#### 引用

使用 `>` 來引用一段文字，例如：
```markdown
> 這是一段引用的文字。
```

#### 代碼塊

使用 \` 來標記內嵌的代碼，例如： \`console.log('Hello, World!')\`。

如果要顯示多行代碼，可以使用三個反引號 (\`) 包圍代碼塊，並指定代碼的語言，例如：
````
```javascript
function greet() {
  console.log('Hello, World!');
}
```
````

這些只是 Markdown 的基礎知識，你可以透過練習和閱讀更多的資源來掌握更多的功能和技巧。現在你可以嘗試在 Hexo 網站中創建一些文章，並使用 Markdown 來編寫它們。
## 3. 配置到 GitHub Pages

回到 hexo 資料夾，在終端機輸入下列指令安裝部署所需套件：
```
$ npm install hexo-deployer-git --save
```

### 步驟 1：創建 GitHub Repository
在 GitHub 上創建一個新的 Repository，Repository 名稱應該是 `<你的GitHub用户名>.github.io`。例如，如果你的 GitHub 用戶名是 `example`，那麼 Repository 名稱就應該是 `example.github.io`。


### 步驟 2：修改 Hexo 配置文件
打開 `_config.yml` 文件，找到 `deploy` 部分，並將其配置如下：

```yaml
deploy:
  type: git
  repository: git@github.com:yourusername/yourusername.github.io.git
  branch: master
```

請將 `yourusername` 替換為你的 GitHub 用戶名。

### 步驟 3：部署到 GitHub Pages
執行以下命令將你的網站部署到 GitHub Pages：

```
hexo clean
hexo deploy
```

等待部署完成後，你的網站就可以在 `https://yourusername.github.io` 上訪問了。

這樣，你就完成了一個簡單的 Hexo 個人網誌的建立、Markdown 編寫和部署到 GitHub Pages 的教學。希望這對你有所幫助！
