## 公式

### 第一章：一階常微分方程式的計算公式總整理 (Sec. 1.1 – 1.5)

| 來源章節 | 類型與目的 | 核心方程式 / 形式 | 計算公式與關鍵技巧 | 
| :--- | :--- | :--- | :--- | 
| **Sec 1.1** | **基本概念與建模** | 顯式形式 ODE | $\mathbf{y' = f(x, y)}$ | |
| | 牛頓第二定律（建模基礎） | $\mathbf{\sum F = m a}$ | | |
| **Sec 1.2** | **數值近似解** | **尤拉法 (Euler's Method)** | $$\mathbf{Y\_n = Y\_{n-1} + hf(x\_{n-1}, Y\_{n-1})}$$ | |
| **Sec 1.3** | **可分離變數 ODE** | **可分離形式** | $\mathbf{g(y) dy = f(x) dx}$ | |
| | **通解** | | $$\mathbf{\int g(y) dy = \int f(x) dx + c}$$ | |
| | **特殊代換：齊次形式** $\mathbf{y' = f(y/x)}$ | 設 $\mathbf{u = y/x}$ ，轉化為 $\mathbf{u' x = f(u) - u}$ | | |
| **Sec 1.4** | **正合 ODE 與積分因子** | **微分形式** | $\mathbf{M(x, y) dx + N(x, y) dy = 0}$ | |
| | **正合性測試** （判別條件） | | $$\mathbf{\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}}$$ | |
| | **潛在函數** $\mathbf{u(x, y)}$ | $\mathbf{u(x, y) = c}$ | | |
| | **求** $\mathbf{u(x, y)}$ | | $\mathbf{u = \int M dx + k(y)}$ 或 $\mathbf{u = \int N dy + l(x)}$ | |
| | **積分因子 $\mathbf{F(x)}$** | | $\mathbf{F(x) = e^{\int R dx}}$ ，其中 $\mathbf{R = \frac{1}{N} \left( \frac{\partial M}{\partial y} - \frac{\partial N}{\partial x} \right)}$ | |
| | **積分因子 $\mathbf{F^*(y)}$** | | $\mathbf{F^*(y) = e^{\int R^* dy}}$ ，其中 $\mathbf{R^* = \frac{1}{M} \left( \frac{\partial N}{\partial x} - \frac{\partial M}{\partial y} \right)}$ | |
| **Sec 1.5** | **一階線性 ODE** | **標準形式** | $\mathbf{y' + p(x)y = r(x)}$ | |
| | **積分因子 $\mathbf{F(x)}$** | $\mathbf{h = \int p(x) dx}$ | $\mathbf{F(x) = e^{h}}$ | |
| | **通解 (General Solution)** | | $$\mathbf{y(x) = e^{-h} \left( \int e^h r(x) dx + c \right)}$$ | |
| | **齊次線性 ODE 通解** ($r(x)=0$) | | $\mathbf{y\_h = c e^{-h}}$ | |
| | **Bernoulli 方程式** | $\mathbf{y' + p(x)y = r(x)y^a}$ | | |
| | **Bernoulli 代換** （簡化為線性） | | $\mathbf{v = y^{1-a}}$ | |




### 第二章：二階常微分方程式計算公式總整理 (Sec. 2.1 – 2.10)

#### 1. 齊次線性 ODE（通用解法）(Sec 2.1)

| 類型與目的 | 核心方程式 / 形式 | 計算步驟與公式 | 
| :--- | :--- | :--- | 
| **通用齊次 ODE 形式** | $\mathbf{y'' + p(x)y' + q(x)y = 0}$ | **降階法** (Reduction of Order)：已知一解 $\mathbf{y\_1}$ 時，求第二解 $\mathbf{y\_2}$。 | |
| **第二解 $\mathbf{y\_2}$ 的一般公式** | $\mathbf{y'' + p(x)y' + q(x)y = 0}$ | $$\mathbf{y\_2 = y\_1 u = y\_1 \int U dx}$$ 其中 $\mathbf{U = \frac{1}{y\_1^2} e^{-\int p(x) dx}}$。 | |

#### 2. 常係數齊次 ODE (Sec 2.2)

ODE 形式： $\mathbf{ay'' + by' + cy = 0}$

| 類型與目的 | 判別條件 | 通解 $\mathbf{y}$ 公式 |
| :--- | :--- | :--- |
| **特徵方程式** (Characteristic Equation) | | $$\mathbf{a\lambda^2 + b\lambda + c = 0}$$ | |
| **情況 I：相異實根** ($\lambda_1 \neq \lambda_2$) | $\mathbf{b^2 - 4ac > 0}$ | $$\mathbf{y = c\_1 e^{\lambda\_1 x} + c\_2 e^{\lambda\_2 x}}$$ | |
| **情況 II：重複實根** ($\lambda$) | $\mathbf{b^2 - 4ac = 0}$ | $$\mathbf{y = (c\_1 + c\_2 x) e^{\lambda x}}$$ | |
| **情況 III：複數共軛根** ($\alpha \pm i\omega$) | $\mathbf{b^2 - 4ac < 0}$ | **組成部分：** $\mathbf{\alpha = -a/2}$ ； $\mathbf{\omega = \sqrt{b - a^2/4}}$ | |
| | | **歐拉公式** ： $\mathbf{e^{i t} = \cos t + i \sin t}$ | |
| | | **實數通解** ： $$\mathbf{y = e^{\alpha x} (A \cos \omega x + B \sin \omega x)}$$ | |

#### 3. 尤拉-柯西方程式 (Euler-Cauchy) (Sec 2.5)

ODE 形式： $\mathbf{x^2 y'' + axy' + by = 0}$

| 類型與目的 | 判別條件 | 通解 $\mathbf{y}$ 公式 | 
| :--- | :--- | :--- | 
| **輔助方程式** (Auxiliary Equation) | | $$\mathbf{m^2 + (a - 1)m + b = 0}$$ | |
| **情況 I：相異實根** ($m_1 \neq m_2$) | | $$\mathbf{y = c\_1 x^{m\_1} + c\_2 x^{m\_2}}$$ | |
| **情況 II：兩重根** ($m_1 = m_2 = m$) | | $$\mathbf{y = (c\_1 + c\_2 \ln x) x^{m}}$$ | |
| **情況 III：複數根** ($\mathbf{m = \alpha \pm i\omega}$) | | $$\mathbf{y = x^{\alpha} [A \cos (\omega \ln x) + B \sin (\omega \ln x)]}$$ | |

#### 4. 非齊次 ODE 的通解結構與方法 (Sec 2.7, 2.10)

非齊次 ODE 形式： $\mathbf{y'' + p(x)y' + q(x)y = r(x)}$

| 類型與目的 | 核心方程式 / 形式 | 計算步驟與公式 | 
| :--- | :--- | :--- | 
| **通解結構** | | **通解結構** ： $$\mathbf{y = y\_h + y\_p}$$ ( $\mathbf{y\_h}$ 齊次解， $\mathbf{y\_p}$ 特解) | |
| **參數變動法 (Variation of Parameters)** | $\mathbf{y'' + p(x)y' + q(x)y = r(x)}$ | **朗斯基行列式 (Wronskian)** ： $\mathbf{W = y\_1 y\_2' - y\_2 y\_1'}$ | |
| | | **特解結構** ： $\mathbf{y\_p = u(x) y\_1 + v(x) y\_2}$ | |
| **特解 $\mathbf{y\_p}$ 的最終公式** | | $$\mathbf{y\_p(x) = -y\_1 \int \frac{y\_2 r}{W} dx + y\_2 \int \frac{y\_1 r}{W} dx}$$ | |

##### 待定係數法 $\mathbf{r(x)}$ 對 $\mathbf{y\_p}$ 形式對照表 (Sec 2.7)

以下適用於常係數非齊次 ODE $\mathbf{y'' + ay' + by = r(x)}$：

| 非齊次項 $\mathbf{r(x)}$ (輸入) | 假設特解 $\mathbf{y\_p}$ 的初始形式 (Output) | 來源依據 |
| :--- | :--- | :--- |
| $\mathbf{k e^{\gamma x}}$ | $\mathbf{C e^{\gamma x}}$ | |
| $\mathbf{k x^n}$ | $\mathbf{K\_n x^n + K\_{n-1} x^{n-1} + \dots + K\_0}$ | |
| $\mathbf{k \cos \omega t}$ 或 $\mathbf{k \sin \omega t}$ | $\mathbf{A \cos \omega t + B \sin \omega t}$ | |
| $\mathbf{k e^{\alpha t} \cos \omega t}$ 或 $\mathbf{k e^{\alpha t} \sin \omega t}$ | $\mathbf{e^{\alpha t} (A \cos \omega t + B \sin \omega t)}$ | |
| $\mathbf{k x^n e^{\lambda x}}$ | $\mathbf{(K\_n x^n + \dots + K\_0) e^{\lambda x}}$ | |
| **修正規則** | 若 $\mathbf{y\_p}$ 形式與 $\mathbf{y\_h}$ 重疊 | 需乘以 $\mathbf{x}$ 或 $\mathbf{x^2}$ (若為重根) | |

#### 5. 物理應用模型 (Sec 2.4, 2.8, 2.9)

| 模型與目的 | 核心方程式 / 形式 | 關鍵公式與技巧 | 
| :--- | :--- | :--- |
| **m-k 無阻尼系統** (Free Undamped) | $\mathbf{my'' + ky = 0}$ | **自然角頻率** ： $\mathbf{\omega\_0 = \sqrt{k/m}}$ | |
| | | **自然頻率 (Hertz)** ： $\mathbf{f = \frac{\omega\_0}{2\pi}}$ | |
| **m-c-k 有阻尼系統** (Damped) | $\mathbf{my'' + cy' + ky = 0}$ | **判別式** 決定形態： $\mathbf{c^2 - 4mk}$ | |
| | | **過阻尼** (I) 通解： $\mathbf{y = c\_1 e^{\lambda\_1 t} + c\_2 e^{\lambda\_2 t}}$ | |
| **m-c-k 強制振動** (Forced) | $\mathbf{my'' + cy' + ky = F\_0 \cos \omega t}$ | **無阻尼共振** $\mathbf{c=0}, \mathbf{\omega = \omega\_0}$ 特解： $$\mathbf{y\_p(t) = \frac{F\_0}{2m\omega\_0} t \sin \omega\_0 t}$$ | |
| **RLC 電路模型** | $\mathbf{LI'' + RI' + \frac{1}{C} I = E'(t)}$ | **機電類比** ： $L \leftrightarrow m$ , $R \leftrightarrow c$ , $1/C \leftrightarrow k$ | |

## 解題

### 詳細解題套路

#### 步驟一：分析與建模

在開始計算前，需要確認問題背景並對 ODE 進行分類：

1.  **確認問題背景：** 判斷問題是否源於具體工程領域（如振動學、熱傳學、電子電路問題等）。若涉及物理系統，必須透過定律建立數學模型：
    *   例如：在力學問題中，使用牛頓第二定律 $\sum F = m a$。
    *   例如：在 RLC 電路中，使用克希荷夫電壓定律（KVL）建立模型。
2.  **確認 ODE 類型：** 判斷方程式的 **階數**（一階 $y'$ 或二階 $y''$）與 **線性**。線性 ODE 具有豐富且標準化的解法結構。

#### 步驟二：數學求解

求解流程取決於 ODE 的階數。

##### A. 一階 ODE 求解套路（First-Order ODEs）

對於一階 ODE，解法通常是透過代數操作或代換，將其轉換為可積分的形式。應依以下順序檢查解法（優先順序高者在前）：

| 解法類型 | 核心方程式 / 形式 | 關鍵步驟與公式 | 
| :--- | :--- | :--- | 
| **1. 線性 ODE** | 標準形式： $\mathbf{y' + p(x)y = r(x)}$ | **計算積分因子：** $\mathbf{F(x) = e^{\int p(x) dx}}$。 **通解：** $\mathbf{y(x) = e^{-h} \left( \int e^h r(x) dx + c \right)}$。 | |
| **2. 可分離變數** | 可分離形式： $\mathbf{g(y) dy = f(x) dx}$ | **直接積分：** $\mathbf{\int g(y) dy = \int f(x) dx + c}$。**注意：必須在積分後立即引入常數 $c$**。 | |
| **3. 正合 ODE** | 微分形式： $\mathbf{M(x, y) dx + N(x, y) dy = 0}$ | **測試：** $\mathbf{\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}}$。**求解潛在函數：** $\mathbf{u(x, y) = \int M dx + k(y)}$ 或 $\mathbf{u = \int N dy + l(x)}$。通解為 $\mathbf{u(x, y) = c}$。 | |
| **4. 積分因子法** (非正合) | $\mathbf{P dx + Q dy = 0}$ (非正合) | 若滿足條件，可求單一變數積分因子： $\mathbf{F(x) = e^{\int R dx}}$ 或 $\mathbf{F^*(y) = e^{\int R^* dy}}$。 | |
| **5. 特殊代換** | 齊次 $\mathbf{y' = f(y/x)}$ 或 Bernoulli $\mathbf{y' + p(x)y = r(x)y^a}$ | **代換：** 齊次設 $\mathbf{u = y/x}$；Bernoulli 設 $\mathbf{v = y^{1-a}}$。 | |

##### B. 二階線性 ODE 求解套路（Second-Order ODEs）

二階線性 ODE 的通解結構為 $\mathbf{y = y_h + y_p}$，即 **齊次解 (Homogeneous Solution)** 加上 **特解 (Particular Solution)**。

###### 階段 I：求解齊次解 $\mathbf{y_h}$

1.  **常係數齊次 ODE** ($\mathbf{ay'' + by' + cy = 0}$):
    *   解 **特徵方程式** $\mathbf{a\lambda^2 + b\lambda + c = 0}$。
    *   根據根的類型構造 $\mathbf{y_h}$：
        *   相異實根 $\lambda_1, \lambda_2$: $\mathbf{y = c_1 e^{\lambda_1 x} + c_2 e^{\lambda_2 x}}$。
        *   重複實根 $\lambda$: $\mathbf{y = (c_1 + c_2 x) e^{\lambda x}}$。
        *   複數根 $\alpha \pm i\omega$: $\mathbf{y = e^{\alpha x} (A \cos \omega x + B \sin \omega x)}$。
2.  **尤拉-柯西 ODE** ($\mathbf{x^2 y'' + axy' + by = 0}$):
    *   解 **輔助方程式** $\mathbf{m^2 + (a - 1)m + b = 0}$。
    *   根據根的類型構造 $\mathbf{y_h}$ (使用 $x^m$、 $x^m \ln x$ 或 $x^{\alpha} \cos(\omega \ln x)$ 形式)。
3.  **降階法 (Reduction of Order)**:
    *   若已知一解 $\mathbf{y_1}$，可利用 $\mathbf{y_2 = y_1 u}$ 求解第二個線性獨立解 $\mathbf{y_2}$。

###### 階段 II：求解特解 $\mathbf{y_p}$（取決於 $\mathbf{r(x)}$）

特解的選擇取決於非齊次項 $\mathbf{r(x)}$ 的複雜程度：

1.  **待定係數法 (Method of Undetermined Coefficients)**:
    *   **適用條件：** 常係數 ODE 且 $\mathbf{r(x)}$ 為簡單形式（多項式、指數、三角函數或其組合）。
    *   **套路：**
        *   **基本規則：** 根據 $\mathbf{r(x)}$ 形式（參照對照表）選擇 $\mathbf{y_p}$ 初始形式。
        *   **修正規則：** 若選擇的 $\mathbf{y_p}$ 中有項與 $\mathbf{y_h}$ 重疊，則必須乘以 $x$ (簡單根) 或 $x^2$ (雙重根)。
        *   **代入求解：** 將修正後的 $\mathbf{y_p}$ 代入原 ODE，透過比較係數來求解末定係數。
2.  **參數變動法 (Variation of Parameters)**:
    *   **適用條件：** $\mathbf{r(x)}$ 形式複雜（如 $\sec x$ 或 $\csc x$）或 ODE 係數為 **變數**。
    *   **要求形式：** ODE 必須是標準形式 $\mathbf{y'' + p(x)y' + q(x)y = r(x)}$。
    *   **套路：**
        *   計算 **朗斯基行列式 (Wronskian)**： $\mathbf{W = y_1 y_2' - y_2 y_1'}$。
        *   **特解公式：** $$\mathbf{y_p(x) = -y_1 \int \frac{y_2 r}{W} dx + y_2 \int \frac{y_1 r}{W} dx}$$

#### 步驟三：結果解釋與應用

1.  **初始值問題 (IVP) 求解：**
    *   對於給定的初始條件 $\mathbf{y(x_0) = K_0}$ 和 $\mathbf{y'(x_0) = K_1}$，必須使用通解 $\mathbf{y = y_h + y_p}$ 及其導數，代入初始條件來確定所有任意常數 $c_1, c_2$。
    *   理論保證：對於具有連續係數的線性 ODE，IVP 總是有 **唯一** 解。

2.  **物理結果解釋 (Interpretation)：**
    *   **系統穩定性：** 若齊次解 $\mathbf{y_h}$ 的所有特徵根（或複數根的實部）均為 **負數**，則 $\mathbf{y_h}$ 稱為 **暫態解** (Transient Solution)，它會隨時間 $t \to \infty$ 趨近於 $0$。
    *   **穩態響應：** 系統的長期行為由 **特解 $\mathbf{y_p}$** 決定，稱為 **穩態解** (Steady-State Solution)。
    *   **共振分析 (Resonance)：**
        *   當外力頻率 $\omega$ 等於系統自然頻率 $\omega_0$ 時，無阻尼系統將發生共振，導致振幅無限增大。
        *   在實際工程應用中，可以通過 **增加阻尼 $c$**、**改變質量 $m$ 或彈簧常數 $k$**（即改變自然頻率 $\omega_n$）或 **避免操作頻率 $\omega$ 接近 $\omega_n$** 來抑制或移除不良共振。
