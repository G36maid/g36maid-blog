## Problem 2 (B)
Prove that $L$ cannot be recognized by a DFA with fewer than 3 states.

To prove this, we analyze all possible cases of DFAs with only 2 states.

### Case 1: Two accept states
A DFA with 2 accept states is impossible because if $b_1 = 0$ in $\Sigma_2$, it will never accept. This leads to an inconsistency, making this configuration invalid.

### Case 2: Zero accept states
A DFA with no accept states is also impossible, as it would accept an empty string, which contradicts the behavior we want. Therefore, this configuration doesn't work.

### Case 3: One accept state
In the DFA from Problem 2(A), we observe that $q_0$ and $q_1$ serve to remember the last column's bit $a_n$. It is necessary to check whether $a_n = b_{n+1}$ to determine if the machine should transition to an error state. Since $q_0$ and $q_1$ behave differently, a single accept state is insufficient to represent the required behavior.

Thus, a DFA with fewer than 3 states cannot recognize $L$.
