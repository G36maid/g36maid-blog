8月20日，一款匿名前沿模型 Ox Alpha（中文圈也叫「牛來」）突然上線，定位是高效 Coding + 長時程 Agent + 真實生產環境使用。

核心規格：
1M上下文,
原生多模態：支援文字 + 圖片 + 影片輸入
最大輸出 13萬 tokens
目前免費（約一週），且承諾 Zero Data Retention（不保留、不用於訓練）
號稱近乎無限額度，日服務容量上看 100T tokens
官方描述強調適合長程軟體工程、複雜推理、以及結合視覺的工作流。

社群指紋分析目前傾向：
多數技術驗證（Tokenizer、API 參數簽名、影片編碼器消耗等）高度指向智譜 Z.ai 的 GLM-5.3 多模態變體 5.3V（公開版 GLM-5.3 是純文字）。
也有人猜是小米 MiMo ，但是猜測因指紋不符而逐漸弱化。

目前官方尚未認領，過去這類 stealth 模型通常會在免費期結束前後公布真實身份。
想要測試的可以去Openrouter 或 OpenCode 直接免費使用
