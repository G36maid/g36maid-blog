```=
find_missing_ids(array, n):
    left = 0,right = n - 3
    
    while left <= right:
        mid = left + (right - left) // 2
        if array[mid] == mid + 1:
            left = mid + 1
        else:
            right = mid - 1
    
    missing1 = left + 1
    
    left = 0,right = left + n - 3
    
    while left <= right:
        mid = left + (right - left) // 2
        if array[mid] == missing1 + mid:
            left = mid + 1
        else:
            right = mid - 1
    
    missing2 = missing1 + left
    
    return missing1, missing2

```
這個演算法的思路是，首先在給定的數組中找到一個缺失的元素，然後在這個元素的那一半數組中找到另一個缺失的元素。

演算法開始時，先初始化左指針 left 為 0，右指針 right 為 n - 3（由於數組長度是 n - 2，減去兩個缺失元素後長度是 n - 4，因此右指針要減 1）。接下來，通過二分查找找到第一個缺失的元素。在每一次迭代中，找到中間元素 mid，檢查中間元素是否等於其本身的 ID（mid + 1），如果是，則缺失的元素在右半部分，否則缺失的元素在左半部分。在二分查找結束時，left 指向的位置就是缺失元素的位置，因此將 left + 1 設為 missing1。

接下來，將左指針 left 重新設為 0，右指針 right 設為 n - 3，再次進行二分查找，在缺失元素所在的那一半數組中找到另一個缺失元素。在每一次迭代中，找到中間元素 mid，檢查中間元素是否等於 missing1 + mid，如果是，則缺失的元素在右半部分，否則缺失的元素在左半部分。在二分查找結束時，missing2 = missing1 + left。

最後，返回 missing1 和 missing2。

由於每次查找都可以將搜索範圍縮小一半，因此時間複雜度為 O(log n)

```=
function fix_linked_list(head):
    if head is NULL or head.next is NULL:
        return head

    curr = head
    prev = NULL
    next = NULL

    while curr.next is not NULL:
        if abs(curr.val) < abs(curr.next.val):
            next = curr.next
            curr.next = next.next
            next.next = curr
            if prev is not NULL:
                prev.next = next
            prev, curr = next, head
        else:
            prev, curr = curr, curr.next

    if prev is NULL:
        head = curr
    else:
        prev.next = curr

    return head
```

```=
findDistance(bikes: List[float], positions: List[int]) -> List[float]:
    n = len(bikes)
    m = len(positions)
    distances = [0] * m  # 用於儲存每個學生停放的自行車到最近的自行車之間的距離
    left_bike_idx = 0  # 左側最近的自行車的索引
    right_bike_idx = 1  # 右側最近的自行車的索引

    # 初始化左側和右側最近的自行車的索引
    while right_bike_idx < n and bikes[right_bike_idx] - positions[0] < positions[m-1] - bikes[left_bike_idx]:
        left_bike_idx += 1
        right_bike_idx += 1

    # 計算每個學生停放的自行車到最近的自行車之間的距離
    for i in range(m):
        pos = positions[i]

        # 更新左側和右側最近的自行車的索引
        while right_bike_idx < n and bikes[right_bike_idx] - pos < pos - bikes[left_bike_idx]:
            left_bike_idx += 1
            right_bike_idx += 1

        # 計算最近的自行車到停放自行車的距離
        if pos - bikes[left_bike_idx] <= 0:
            distances[i] = bikes[right_bike_idx] - pos
        elif right_bike_idx == n or bikes[right_bike_idx] - pos <= 0:
            distances[i] = pos - bikes[left_bike_idx]
        else:
            distances[i] = min(pos - bikes[left_bike_idx], bikes[right_bike_idx] - pos)

    return distances
```
