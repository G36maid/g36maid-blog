# 以校園戀愛故事 探討戀愛關係發展

## 關係
普通關係
* 疏離
* 冷漠
* 背叛

戀愛關係
* 親密
* 激情
* 承諾

## 階段

### 攜手五階段
1. 初始
2. 實驗
3. 強化
4. 整合
5. 聯繫
### 分離五階段
1. 差異
2. 限制
3. 停滯
4. 迴避
5. 終結

## 樹狀圖

* 戀愛
    * 冷卻
        * 磨合
        * 迴避
    * 升溫
        * 幸福與承諾
## 層面
愛情的四個行為層面
1. 友伴
2. 性／繁衍
3. 依附
4. 照顧
這些條件在青少年時期較難以完全理解與達成，也缺乏溝通，容易使關係劣化

青少年戀愛
* 深刻
    * 共同經歷許多第一次體驗的事物
* 脆弱
    * 各種經驗不足
    * 缺乏成熟思考
    * 害怕未來
