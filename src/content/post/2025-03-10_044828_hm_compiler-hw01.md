## **1. BNF Grammar**
We define a simple BNF grammar for arithmetic expressions:

```bnf=
<expr> ::= <expr> + <term> | <term>
<term> ::= <term> * <factor> | <factor>
<factor> ::= ID | ( <expr> )
```

## **2. Derivation Steps**
We derive the expression `ID * (ID + ID * ID)` step by step.

1. `<expr> → <term>`
2. `<term> → <term> * <factor>`
3. `<term> → ID`
4. `<factor> → ( <expr> )`
5. `<expr> → <expr> + <term>`
6. `<expr> → ID`
7. `<term> → <term> * <factor>`
8. `<term> → ID`
9. `<factor> → ID`

## **3. Derivation Tree (in Markdown)**

```plaintext=
    <expr>
       │
    <term>
       │
 ┌─────┴──────┐
 │         <factor>
 │            │
 │       ┌─( <expr> )─┐
 │       │            │
 │       │      ┌─────┴──────┐
 │       │      │            │
 │       │    <expr>    +   <term>
 │       │      │             │
 │       │      │      ┌──────┴───────┐
 │       │      │      │              │
 │       │      │     <term>   *   <factor>
 │       │      │      │              │
ID       *     ID     ID              ID
```
