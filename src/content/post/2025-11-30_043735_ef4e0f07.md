最近在做 Brainfuck 的編譯器 (brainfuck-rs)，為了證明把 Brainfuck 轉成 Rust 再編譯成 Native code 比起直譯真的比較快，需要一個嚴謹的 Benchmark。

順便練一下在高等編譯器學的的最佳化技巧。

強烈推薦 hyperfine ，一個 CLI benchmark 工具

1.  Warmup：避免 Disk I/O 或 Cache 冷啟動影響數據（這點超重要）。
2. 統計分析：跑多次取平均，自動偵測並警告 outlier。
3. 比較模式：直接把兩個指令丟進去，它會告訴你 A 比 B 快幾倍。

除了上面這些還支援超多種輸出，直接 output 成 Markdown attach 在 Readme 後面或是接成 GitHub action , 輸出成 json 供其他程式分析都很實用
