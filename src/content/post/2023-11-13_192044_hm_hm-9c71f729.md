複雜度（Complexity）用來分析一個解法所需的計算量與記憶體空間，
藉此比較解法的優劣、幫助選擇與取捨。

在競程，程式被要求必須在限制時間內執行完畢，
因此複雜度也被用來分析解法是否可行，甚至從題目限制範圍逆推出解題線索。

不會分析，就無法判斷好壞，也就無法進行取捨和改進。

## 時間與空間複雜度 Time / Space Complexity
由於電腦在硬體上有所不同時，同樣的做法所需時間不同；
但電腦每秒能進行的計算量是固定的，執行所需時間會與所需計算量成正比，
因此時間複雜度指的是計算量，而不是以耗時來估算。

空間複雜度則是計算過程中，同一時刻最大所需儲存空間。

由於空間不使用也是浪費，且空間通常不影響時間，
通常能用更大的空間換取更少的計算量時，
除非空間不在合理範圍內，否則絕對是換了更加划算。

如果省略不提是哪一種複雜度，單純說「複雜度」時，通常指時間複雜度。

## 估算複雜度時的考量

在資料量不大的情況下，執行時間的差異相對不重要；
百分之一秒和萬分之一秒雖差了一百倍，幾乎感覺不出差異，
但如果是一天和一百天呢？

通常會是資料量龐大時，會特別需要注意計算量的問題。
我們說一個解法比較好，通常是看資料量大時的表現較佳，
即使在資料量不大時表現不佳也一樣。

因此，我們首重資料量對計算量的成長速度。

影響計算量的細節實在太多，像是同樣一次運算，
加減乘除間實際需要的指令數並不相同；
做法在轉成程式碼後，也會因實作細節出現差異，不同語言也會出現差異。

因此，我們省略常數等細節帶來的差別。

大部份時候，我們更在意極端情況下的好壞，
如同我們只在意下大雨時會不會淹水，完全不會去管毛毛雨甚至沒雨時的情境。

因此，我們悲觀地看最差條件下所需的計算量。

## 複雜度的定義

複雜度的定義之一是使用 Big O 表示法。Big O 表示法是一種用來描述算法執行時間或空間需求隨著輸入大小的增加而增長的上限界定符號。

在 Big O 表示法中，我們使用 "O" 後面跟著一個函數，該函數描述了算法的執行時間或空間需求。這個函數通常是輸入大小 n 的某個函數，表示算法的執行時間或空間需求與輸入大小 n 呈現某種上限的關係。

以下是一些常見的 Big O 表示法：

1. **O(1):** 常數時間複雜度。表示算法的執行時間或空間需求是固定的，不隨輸入大小而變化。

2. **O(log n):** 對數時間複雜度。表示算法的執行時間或空間需求隨著輸入大小的對數增長。

3. **O(n):** 線性時間複雜度。表示算法的執行時間或空間需求與輸入大小成線性關係。

4. **O(n log n):** 線性對數時間複雜度。表示算法的執行時間或空間需求隨著輸入大小的對數增長，但比純粹的對數增長更快。

5. **O(n^2):** 平方時間複雜度。表示算法的執行時間或空間需求與輸入大小的平方成正比。

6. **O(2^n):** 指數時間複雜度。表示算法的執行時間或空間需求隨著輸入大小的指數增長。

Big O 表示法的目的是提供一種簡潔的方式，讓我們能夠在不考慮細節的情況下，快速了解一個算法的性能特點。當我們討論複雜度時，我們通常關注的是最壞情況下的執行時間或空間需求。

另外還有 little o $o(n)$ 與 omega $\Omega(n)$

$O(g(n))$={$f(n)$: $\exists$ c,$n_0$>=0 , 0<= $f(n)$ <= $cg(n)$ for all $n$ >= $n_0$ }

$\Omega(g(n))$={$f(n)$: $\exists$ c,$n_0$>=0 , 0<= $cf(n)$ <= $g(n)$ for all $n$ >= $n_0$ }

$\Theta(g(n))$={$f(n)$: $\exists$ $c_1$,$c_2$,$n_0$ >=0 , 0<= $c_1g(n)$ <= $f(n)$ <= $c_2g(n)$ for all $n$ >= $n_0$ }

這些證明就留給演算法老師了吧。

## 複雜度的計算

可行性分析
將資料量 $n$代入複雜度，可大略估算出所需空間和計算量。

空間在計算後約在 1000 萬內都算安全，到 1 億以內還可以嘗試；
超過就算不合理的範圍。

時間在計算後約在 100 萬內都算安全，1000 萬內還算合理，
到 1 億以內有危險，但不是完全沒機會；超過就算不合理範圍。

例如一道題目 n=2000，而你找到了一個 O(n^2) 的解法，
代入得到 4,000,000 還算合理範圍內；但若是 O(n^3) 的解法，
代入得到 8,000,000,000 明顯不合理，通常無法在時限內跑完。

反過來看，一道題目 n=2000 要在安全範圍內大概是O(n^2)
最差可能會到 O(n^2log(n))，也許可以透過這種方法找到正解的提示。
