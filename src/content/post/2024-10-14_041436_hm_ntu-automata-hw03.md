## Problem 1

Variables:
- $\Sigma = \{ 0 ,1\}$
- $B = \{ uv \mid u \in \Sigma^*, v \in \Sigma^*\ | \ \Sigma , |u| \geq |v| \}$

- $C = (V, I, R, 3)$ 
- $V = [A, B]$ 
- $I = 50, 13$ 
- $S = A$ 

$R$  is given by:

$$
A \rightarrow OAO \ | \ OBI \ | \ IAO \ | \ IBI
$$
$$
B  \rightarrow  OBO  \ | \  OBI \ | \ IBO \ | \ IBI  \ | \ 0 \ | \ 1  \ | \ \varepsilon
$$

$$
S_0 \rightarrow XD \ | \ U_4U_1 \ | \ U_4U_2 \ | \ U_4U_3 \ | \ U_4U_5 \ | \ U_4U_6
$$

S \rightarrow XD \ | \ U_4U_1 \ | \ U_4U_2 \ | \ U_4U_3 \ | \ U_4U_5 \ | \ U_4U_6
