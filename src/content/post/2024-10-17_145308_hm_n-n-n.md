# cp1 hw2 update
第三題<=1 代表error
保證 double 不會暴
第四題保證 RGB 為 R,G,B
第四題請使用雙線性差值
第五題螢幕大小是固定的
第五題保證 arch logo 大小最小高度為三
保證 fastfetch 寬度能正常顯示
因為寬度限制導致 arch logo 的錯誤不扣分

明天早上我會提供一些範例測資提供參考

arch logo 必須盡可能填滿pane（以高度為主） 
TMUX green color code = #00FF00


遇到不被3整除的 arch logo 高度，
小三角形你使用哪種都是對的

```=
$ fastfetch
    /\
   /oo\
  /oooo\
 /oooooo\
/ooo/\ooo\
```

```=
   /oo\
  /oooo\
 /oo/\oo\
/oo/  \oo\
```
