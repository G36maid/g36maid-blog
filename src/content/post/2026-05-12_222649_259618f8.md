NVIDIA 發布 CUDA-Oxide ，一個實驗性 Rust-To-CUDA 編譯器

CUDA-Oxide 0.1 是 這款實驗性 Rust 轉 CUDA 編譯器的首個版本，旨在讓開發者能以「相對安全」的方式，使用 Rust 程式語言編寫 SIMT GPU 核心。CUDA-Oxide 能將標準的 Rust 程式碼直接轉譯為 NVIDIA PTX 格式。

CUDA-Oxide 由 NVIDIA 工程師設計，旨在實現單一來源編譯、裝置端抽象化，以及透過自訂 rusc 編譯器後端來建構的 Rust 原生編譯管線。

雖然目前仍處於實驗階段，但這個新的開源專案對於希望直接從原生 Rust 程式碼處理 CUDA 的開發者而言，無疑是一大進步。

目前 Rust + CUDA 生態系包含了
Rust-GPU / rust-cuda / CubeCL / std::offload / cudarc / wgpu 等
每個目標，範圍與達成方式各不相同，比較與差異可在此查看:
https://nvlabs.github.io/cuda-oxide/appendix/ecosystem.html

有興趣進一步了解 CUDA-Oxide 或試用首個 v0.1 版本的用戶，可查看 GitHub 上的 NVLabs 專案。
The cuda-oxide Book
https://nvlabs.github.io/cuda-oxide/
GitHub
https://github.com/NVlabs/cuda-oxide
