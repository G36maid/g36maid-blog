> 本文擴寫自 2026-04-13 的 HackMD 考前筆記，擴寫時間 2026-11-21。原稿是期中考前一晚趕出來的重點整理，範圍從半導體物理到 BJT 直流分析；這裡把它重排成能讀的複習順序，順便把當時靠硬背的口訣補上「為什麼」。原稿附的上課截圖（HackMD 外連）已因無法取得而移除，公式與表格都保留在文字裡。

期中考前的電子學很難念。前幾章是名詞轟炸：載子、摻雜、空乏區；後半是模型轟炸：二極體三種模型、三種整流器、四種特殊二極體、BJT 三個工作區。單看每一節都懂，混在一起考就會把 0.7V 放錯地方、把橋式整流的 1.4V 寫成 0.7V。這篇照「半導體 → 二極體 → 整流器 → 限幅箝位 → 特殊二極體 → BJT」的順序整理，每節只留考試真的會用到的東西。

## 半導體物理：一切壓降的源頭

純矽（本徵半導體）的載子來自熱激發，數量少、導電差；摻雜之後才變有用。摻五價元素得 N 型，多數載子是電子；摻三價元素得 P 型，多數載子是電洞。

PN 接面是後面所有二極體行為的根：接面處形成沒有載子的空乏區，並帶出一個障壁電位——矽約 $$0.7V$$。這個 0.7V 會一路糾纏到整流器、限幅器、箝位器、BJT 的 $$V_{BE}$$，整份考卷都是它。順偏（P 接正、N 接負）空乏區縮小、導通；逆偏空乏區擴大、截止。記住「順偏才過、過路費 0.7V」，後面幾種模型都是在修這句話的精確度。

## 二極體三種模型：考試寫哪種

1. **理想模型**：順偏短路（0V）、逆偏斷路。好算，但電壓會差 0.7V。
2. **實際模型**：順偏視為 0.7V 壓降、逆偏斷路。考試最常用，題目沒特別聲明就用它。
3. **完整模型**：多考慮順向電阻 $$r_d'$$ 與逆向電阻 $$r_R'$$，順偏時：

$$I_F = \frac{V_{BIAS} - 0.7V}{R_{LIMIT} + r_d'}$$

實際模型和完整模型的差別只在 $$r_d'$$ 通常遠小於 $$R_{LIMIT}$$，一般題目直接忽略；逆向偏壓時才需要把 $$r_R'$$ 放回分壓。判斷題問哪個模型最常考，答案是實際模型。

## 整流器：三種電路一張表

先補換算：匝數比 $$n = N_s/N_p$$，降壓變壓器 n = 1:4 表示二次側電壓是一次側除以四；峰對峰值先除以二得峰值；看到 RMS 值先乘 $$\sqrt{2}$$ 轉峰值再進公式。

| 特性 | 半波 | 中心抽頭 | 橋式 |
| :--- | :--- | :--- | :--- |
| 輸出峰值 $$V_{p(out)}$$ | $$V_{p(sec)} - 0.7V$$ | $$V_{p(sec)}/2 - 0.7V$$ | $$V_{p(sec)} - 1.4V$$ |
| 平均電壓 $$V_{avg}$$ | $$V_{p(out)}/\pi \approx 0.318V_{p(out)}$$ | $$2V_{p(out)}/\pi \approx 0.636V_{p(out)}$$ | 同中心抽頭 |
| PIV（逆向耐壓） | $$V_{p(sec)}$$ | $$V_{p(sec)} - 0.7V$$ | $$V_{p(out)} + 0.7V$$ |
| 輸出頻率 | $$f_{in}$$ | $$2f_{in}$$ | $$2f_{in}$$ |

橋式的 1.4V 來自「兩顆二極體同時導通」，每顆 0.7V，這是最常被寫錯的數字。中心抽頭的 PIV 有兩種算法：$$V_{p(sec)} - 0.7V$$ 和 $$2V_{p(out)} + 0.7V$$，兩條其實等價——因為 $$V_{p(out)} = V_{p(sec)}/2 - 0.7V$$，代回去就得到 $$2V_{p(out)} + 0.7V = V_{p(sec)} - 0.7V$$。考試時哪個條件給得多就用哪條，不用慌。濾波則記一件事：$$R_L$$ 或電容 $$C$$ 越大，漣波因子 $$r$$ 越小。

## 限幅與箝位：一個看並聯、一個看串聯

限幅器切掉部分波形，二極體與負載**並聯**；箝位器平移整個波形，二極體（含電容）與負載**串聯**。先分並聯還是串聯，就分出了這兩種電路，接著才看二極體箭頭：

- **限幅器**：二極體向下 → 正限幅，切掉上方；向上 → 負限幅，切掉下方。
- **箝位器**：二極體向上 → 正箝位，波形上移；向下 → 負箝位，波形下移。

為什麼限幅器箭頭向下反而切掉正半週？因為二極體與負載並聯：當輸入把輸出節點往上推到超過 0.7V，向下的二極體恰好順偏導通，把多出來的電壓短路在自己身上，輸出於是被釘在 0.7V 附近，上方就被切掉了。箭頭向上時同理，換負半週被釘住。導通的時機決定切哪邊，箭頭只是標出「什麼極性會讓它順偏」，口訣本身是導通條件的速記。

箝位器靠電容記住峰值：正箝位中電容充到 $$V_C = V_{p(in)} - 0.7V$$，之後這個電壓疊加在輸出上，把整個波形往上抬。所以箝位器不改變峰對峰值（$$V_{p-p(out)} = V_{p-p(in)}$$），只做整體平移；0.7V 在這裡是「電容充不滿的損耗」，角色和整流器的壓降不同。

限幅位準是 $$V_{bias} \pm 0.7V$$，注意電池極性。若電路裡有串聯電阻，導通半週照分壓算：$$I = (V_{in} - 0.7V)/(R_1 + R_2)$$，$$V_{out} = 0.7V + I \cdot R_2$$。

## 特殊二極體：各走各的偏壓

- **齊納**：運作在逆向崩潰區，做電壓調整；等效模型是 $$V_Z$$ 串小阻抗 $$Z_Z$$。
- **變容二極體**：用逆向偏壓調電容量。
- **LED**：順偏，$$V_F \approx 1.2V \sim 3.2V$$。
- **光二極體**：逆偏，光越強逆向電流越大，成正比。

四種裡三種是逆偏家族（齊納、變容、光二極體），只有 LED 順偏。用偏壓方向分組記，比逐個死背省事。

## BJT 直流分析：Duel Rule

核心公式四條：$$I_E = I_C + I_B$$、$$I_C = \beta_{DC} I_B$$、$$I_E = (\beta_{DC}+1)I_B$$、$$\alpha_{DC} = I_C/I_E = \beta/(\beta+1)$$。偏壓電路再加三條：$$I_B = (V_{BB} - 0.7V)/R_B$$、$$V_{CE} = V_{CC} - I_C R_C$$、$$V_{CB} = V_{CE} - V_{BE}$$。

區域判定是整份筆記我最想留的東西，筆記裡叫它 Duel Rule：

1. $$V_{BE} < 0.7V$$ → **截止**：$$I_B = 0$$、$$I_C = 0$$、$$V_{CE} = V_{CC}$$。
2. 算「理想需求」$$I_{C(ideal)} = \beta_{DC} \times I_B$$，再算「現實極限」$$I_{C(sat)} = (V_{CC} - 0.2V)/R_C$$。
3. 理想需求 > 現實極限 → **飽和**（$$I_C = I_{C(sat)}$$、$$V_{CE} \approx 0.2V$$）；否則 → **主動區**（$$I_C = \beta I_B$$、$$V_{CE} = V_{CC} - I_C R_C$$，放大器就工作在這裡）。

為什麼需求超過極限就是飽和？β 只是放大倍率的「意願」，集極電流最終受外電路限制：就算 β 說要給 $$\beta I_B$$ 那麼大的電流，電源經 $$R_C$$ 最多也只能供給 $$(V_{CC} - 0.2V)/R_C$$——電流再大會把 $$V_{CE}$$ 壓到 0.2V 以下，物理上做不到。需求給不出來，電晶體就卡在底部，這就是飽和。反過來，需求在極限之內，電路照 β 的劇本走，落在主動區。這樣理解之後，這條規則就從口訣變成推論，臨場不會懷疑自己背反了。

開關設計是反推題：先算 $$I_{C(sat)}$$，再算飽和所需最小基極電流 $$I_{B(min)} = I_{C(sat)}/\beta_{DC}$$，最後 $$R_{B(max)} = (V_{IN} - 0.7V)/I_{B(min)}$$。

## 應考提醒

1. 單位：$$mA \times k\Omega = V$$，最省事也最容易出錯的換算，小數點別漂。
2. 看到 RMS 先乘 $$\sqrt{2} \approx 1.414$$ 轉峰值，再進整流器公式。
3. 畫輸出波形時把峰值電壓標出來，光畫形狀會被扣分。
4. 橋式整流壓降是 1.4V，中心抽頭是 0.7V，別互通。

考後回顧一句話：Duel Rule 和「並聯切波、串聯搬波」兩個框架撐起了整份考卷，先懂 why 再背口訣，臨場才有辦法自己驗算。
