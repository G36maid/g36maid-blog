# 🏠 Homelab 2025 規劃

---

## 0. 基礎架構 (Infrastructure)

* [ ] **虛擬化/儲存平台 (Hypervisor / NAS OS)**
    * [x] **Proxmox VE** → 開源的虛擬化管理平台 (Hypervisor)，整合 KVM 虛擬機和 LXC 容器，功能強大且靈活。
    * [ ] **TrueNAS SCALE** → 以 Debian 為基礎的 NAS 系統，原生支援 ZFS 檔案系統、Docker 與虛擬機，強項在於資料儲存與安全。
    * [ ] **Unraid** → 簡單易用的 NAS 系統，特色是彈性的硬碟陣列，社群應用豐富，適合家庭媒體伺服器。

---

## 1. Admin / Control

* [ ] **容器管理介面 (Container Management)**
    * [x] **Portainer** → 功能全面，圖形化介面直觀易上手。
    * [ ] **Yacht** → 介面更現代化，但功能相對較少。
* [ ] **容器自動更新 (Container Auto-Update)**
    * [ ] **Watchtower** → 設定即忘，穩定可靠。
    * [ ] **Ouroboros** → 另一種選擇，功能相似。
* [ ] **反向代理 (Reverse Proxy)**
    * [ ] **Nginx Proxy Manager (NPM)** → 圖形化設定，對新手友好，申請 SSL 證書非常簡單。
    * [x] **Traefik** → 自動化服務發現，透過 Docker Label 設定，適合自動化與大規模部署。
    * [ ] cert manager
* [ ] **單點登入 (SSO)**
    * [ ] **Authelia** → 輕量級，專注於身份驗證與 2FA，設定相對單純。
    * [ ] **Authentik** → 功能極其強大，是完整的身份提供者 (IdP)，但設定也更複雜。
* [ ] **密碼管理 (Password Manager)**
    * [x] **Vaultwarden** → Bitwarden API 的 Rust 實作，輕量高效。

## 2. Monitor

* [ ] **即時效能監控 (Real-time Monitoring)**
    * [x] **Netdata** → 每秒級別的高精度監控，圖表華麗。
* [ ] **長期趨勢監控 (Long-term Monitoring)**
    * [ ] Prometheus
    * [ ] Grafana
    * [ ] loki ?
* [ ] **服務狀態頁面 (Status Page)**
    * [ ] **Uptime Kuma** → 美觀易用的服務監控頁面，支援多種通知方式。
* [ ] **硬碟/輕量監控**
    * [ ] **Scrutiny** → 專注於 S.M.A.R.T. 硬碟健康監測與報告。
    * [x] **Beszel** → 輕量級的容器/主機儀表板。

---

## 3. Entrypoint / Dashboard

* [ ] **開源防火牆/路由器 (Firewall/Router)**
    * [x] **OPNsense** → 介面現代化，更新週期較快。
    * [ ] **pfSense** → 以穩定性著稱，社群歷史悠久。
    * [ ] * bind9 ?
* [ ] **VPN 服務**
    * [x] **Tailscale** → 商業服務，設定簡單，穿透能力強。
    * [x] **Headscale** → Tailscale 的開源自建控制伺服器，提供完全掌控。
* [ ] **安全對外通道 (Secure Tunnel)**
    * [x] **Cloudflare Tunnel** → 無需公網 IP 或開 Port，安全地將內部服務公開。
* [ ] **DNS 廣告過濾 (Ad Blocker)**
    * [ ] **AdGuard Home** → 功能較多，原生支援 DoH/DoT，介面新穎。
    * [ ] **Pi-hole** → 老牌穩定，社群龐大，黑名單資源豐富。
* [ ] **個人儀表板 (Dashboard)**
    * [x] **Homepage** → 高度客製化，可透過 API 整合 Docker 等上百種服務，功能最強大。
    * [ ] **Homarr** → 介面美觀，也支援部分服務 API 整合。
    * [ ] **Dashy** → 功能豐富，客製化選項多，支援多種狀態監控 Widget。
    * [ ] **Heimdall** → 老牌 Dashboard，簡單點擊新增。
    * [ ] **Homer** → 純靜態，透過 YAML 設定檔驅動，簡單輕量。

## 4. Media

* [ ] **影音串流伺服器 (Media Streaming)**
    * [x] **Jellyfin** → 完全開源，社群活躍，功能完整。
    * [ ] **Plex** → 用戶體驗流暢，客戶端支援廣泛，但部分進階功能需付費。
* [ ] **自動化媒體管理 (The \*Arr Suite)**
    * [ ] Sonarr (影集), Radarr (電影), Lidarr (音樂), Readarr (書籍), Prowlarr (索引器)
* [ ] **媒體請求平台 (Media Request)**
    * [ ] **Overseerr** → 專為 Plex 設計，UI 精美。
    * [ ] **Jellyseerr** → Overseerr 的分支，完美支援 Jellyfin 和 Sonarr。
* [ ] **相片管理 (Photo Management)**
    * [x] **Immich** → Google Photos 的強力替代品，積極開發中。
* [ ] **音樂串流 (Music Streaming)**
    * [ ] **Navidrome** → 輕量級，資源消耗低，介面簡潔。
* [ ] **電子書庫 (E-book Library)**
    * [ ] **Calibre-Web** → 為你的 Calibre 書庫提供優雅的 Web 介面。

## 5. File & Documents

* [ ] **Web 檔案管理**
    * [x] **Filebrowser** → 簡單、快速、輕量。
* [ ] **私有雲/檔案同步 (Cloud/File Sync)**
    * [x] **Nextcloud** → 功能全面的私有雲，整合日曆、聯絡人、Office 等。
    * [ ] **Seafile** → 以檔案同步與共享為核心，效能與穩定性著稱。
* [ ] **點對點同步 (P2P Sync)**
    * [x] **Syncthing** → 去中心化的點對點檔案同步工具，安全、私密。
* [ ] **無紙化辦公 (Paperless Office)**
    * [ ] **Paperless-ngx** → 將實體文件掃描、OCR 辨識、歸檔和索引。
* [ ] **PDF 工具箱**
    * [x] **Stirling-PDF** → 對 PDF 執行合併、分割、旋轉等各種操作的 Web 工具。
